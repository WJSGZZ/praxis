# 模型

按methods核心定义问题，产tasks/requirements/model-contract；门禁通过交compute。

沿主入口加 `--stage model`。仅结构、可辨识性/界或机制不明时用 `--detail routes`；另可单选math或domain；缺数据给有据情景及恢复输入。
