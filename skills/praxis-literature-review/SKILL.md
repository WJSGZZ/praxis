# Praxis · 文献检索与综合

BUNDLE=`praxis` 技能目录；脚本 `BUNDLE/scripts/`；Python 3.12、uv（`uv run --locked`）；无终端仅设计。执行见 [automation.md](../../references/automation.md)。

## 做什么

- 按 [literature-review.md](../../references/literature-review.md) 选参数／公式核证、研究定位、证据综合或系统综述模式，明确范围与纳排。
- 读外部材料前按 [integrity.md](../../references/integrity.md)“材料暴露”及 [learning-loop.md](../../references/learning-loop.md) 核许可；实际检索与筛选范围留痕。
- `search_literature` 找候选与开放全文；作者稿、机构库、出版社或已装 arXiv 入口用于阅读；`find_open_access` 仅用已授权的真实联系邮箱。
- 按 [writing.md](../../references/writing.md) 核原句、式、表、版本、对象、单位与条件；DOI 元数据检查与论断支撑分别完成。
- 按问题／机制／方法综合，说明样本和信息条件差异，合并同研究多报告；缺全文或服务失败如实标阅读范围与待核事项。
- 交可复查检索、来源—论断定位、实质比较及限制；系统综述另交筛选和研究—报告关联，检索使用免费且获准入口。
