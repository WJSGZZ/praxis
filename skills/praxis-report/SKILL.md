# 论文与交付

接有效原稿/证据/未决项，按writing核心组稿；竞赛加checklist/delivery，研究加`--detail research`。缺证回科学任务，修订追实际影响。

沿主入口加 `--stage report`。纯语言修改只读“语言专项”（`--detail writing-language`），不新增科学主张。竞赛用paper_template生成骨架，特殊组件或接口不清才用 `--detail delivery-api`，读者字段不清用reader-api。整稿评价另交review。
