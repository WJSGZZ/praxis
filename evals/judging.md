# 评委说明与评分表（第二版：条目核对为主，印象为辅）

评委（人或模型）收到：赛题题面（含渲染页）、被评论文（文本与图）、本评分表。评委不知道论文由谁写；多篇论文的顺序随机；评委独立打分，不看其他评委的分数。

## 原则

1. **先核对，后给分。** 每个维度由一组可对照的条目组成，每条回答“满足／不满足”并附证据位置（页码、公式号、数值）；维度分由满足的比例换算，不由印象决定。
2. **印象只能微调。** 每个维度允许评委加减至多 1 分（`adjust`），必须写明理由；没有理由的调整无效。
3. **标明依据。** 每个维度注明分数主要来自 `computed`（复算、规则检查、数字比对）还是 `judgment`（评委的判断），后者在汇总时单独列出。
4. **复算独立。** 评委自己写程序重算关键数字，不使用论文的程序；规则与数字一律对照渲染的题面页核对，两种读法都可能时各算一遍。找不到错误不等于没有错误，要写明检查了什么。

## 评分表

每个条目用 `met: true|false`；维度分 = 4 × 满足条目数 ÷ 条目总数（四舍五入到 0.5），再加 `adjust`（−1 到 +1），结果限制在 0–4。

| 维度（权重） | 条目 |
|---|---|
| 问题理解与题意覆盖（10） | C1 每个小问都有明确回答，带数值与单位；C2 题给数据全部用到，或明说不用及原因；C3 列出题面的模糊处与采用的读法，对决定整关结论的歧义另算另一种读法；C4 有“要求—位置”对照 |
| 假设的合理性（15） | A1 每条假设有理由；A2 会改变结论的关键假设经过检验（情景或敏感性）；A3 每条关键假设写明不成立时怎么办；A4 没有假设与题面或数据矛盾（评委对照数据核对）；A5 参数有出处和范围 |
| 模型的建立与创新（15） | M1 机制与量纲、极限情形核对过；M2 至少一条替代路线被数字地比较或淘汰；M3 复杂度升级有具体理由（简单一层解释不了什么）；M4 能退化为已知特例并与之一致；M5（判断项）抓住问题的结构，有超出套路的见解并说明为什么 |
| 结果的正确性（25） | K1 评委独立复算与论文的关键数字一致（`computed`）；K2 论文内有独立检查（解析极限、守恒、另一种方法）；K3 被约束或被优化的量对网格、步长或样本量收敛；K4 评委回放时约束成立；K5 摘要、正文、表中的数字互相一致 |
| 稳健性与敏感性（10） | R1 扰动针对可能改变结论的因素；R2 标定过的参数在扰动后重新标定再预测；R3 结论强度与证据相称，给出范围；R4 写明适用范围 |
| 文字与排版（10） | W1 摘要含问题、方法、带单位的定量结果；W2 只读摘要和结论就能找到每问的答案；W3 图的坐标轴有量与单位，图注写明它支持的论断；W4 格式规则检查通过（`scripts/contest_rules.py`）；W5（判断项）语言自然，没有工具与流程说明、翻译腔或套话 |
| 可核查性与诚实（15） | V1 附录代码能复现全部数字（评委至少运行了关键部分）；V2 数据与参数来源有引用；V3 AI 使用声明真实；V4 声称做过的检查与实际检查一致，没有夸大；V5 局限如实写明 |

只有一个条目也属于判断项的维度（M5、W5）按同样比例换算；评委在 `basis` 中如实标注。

## 输出格式（JSON）

```json
{"paper": "A",
 "checklist": {"coverage": {"C1": {"met": true, "evidence": "表 1，第 3 页"}, "C2": {"met": false, "evidence": "附件第 2 表未使用"}},
               "correctness": {"K1": {"met": true, "evidence": "复算 17.58 mm，论文 17.57 mm"}}},
 "adjust": {"model": {"value": 1, "reason": "…"}},
 "basis": {"coverage": "computed", "model": "judgment"},
 "errors_found": ["具体的错误，附位置"], "overall_note": "一两句"}
```

另有一项 `award_estimate`：按该赛事的奖项档次给出范围、依据和不确定度（国赛：国一、国二、省一、省二、省三、未获奖；美赛：Outstanding、Finalist、Meritorious、Honorable Mention、Successful Participant）。这是评委的估计，不是校准过的预测：我们没有带获奖等级标注的数据，只有评分表分数和与真实获奖论文的盲对比两个锚点，所以只给范围，不给精确概率，并写明“未校准”。

```json
"award_estimate": {"most_likely": "省一", "range": ["省二", "国二"], "basis": "复算全部一致；摘要缺推荐方案与金额", "calibrated": false}
```

维度键：`coverage`、`assumptions`、`model`、`correctness`、`robustness`、`writing`、`verifiability`。也可以直接给 `scores`（0–4）；`evals/aggregate.py` 两种都接受，有 `checklist` 时按上面的规则自动换算。

## 阅读评委（另一种模式）

模拟真实评委的限时阅读：只给摘要、图表与图注、结论，不让复算，限时十分钟，回答：每问的答案是什么？为什么可信？最想追问哪一点？按国赛章程的四条标准（假设的合理性、建模的创新性、结果的正确性、文字表述的清晰性）各给 0–4 分并写一句理由。它的分数不并入上表，单独报告：它测的是评委读不读得懂、找不找得到得分点。

## 要避免的偏差

- 篇幅长不等于好；图多不等于好；用词专业不等于正确；
- 先独立判断数值是否合理（量级、单位、极限情形），再看论文自己的说法；
- 与参考论文比较时只比较内容，不比较篇幅与排版；
- 同一模型家族的评委会有共同的盲点（例如与作者读错同一个规则）：所以复算必须独立、规则以渲染页为准。

## 校准

1. 评委先对一份已知较强的和一份故意削弱的论文打分。削弱的方法：删去检验、敏感性与局限，把关键结论改成未经检验的断言，改一个关键数字，加入空话。分不出高低、或对注入的错误不扣分的评委不采用；记录每种注入被哪些条目抓住。
2. 被测论文与校准论文混排、顺序随机；
3. 同一份论文换顺序评两遍，取一致的部分；两遍相差大于一档（4 分制中 1 分）的维度标为不稳定。

不同赛事的差异只放在 `evals/profiles.json` 这份数据里（权重、官方评阅标准的名称、硬性规则的检查入口，以及每一项的来源和核对日期），评分表与流程共用；新增赛事只加一份档案，不新增技能。没有对应档案时用 `general`，并标明未按赛事校准。`--contest=cumcm|mcm` 取对应档案的权重；其中权重是我们自定的工作值，不是官方的，美赛的评阅标准也未对照 COMAP 的评审文件核对，档案里的 `source` 字段逐项写明。

聚合用 `evals/aggregate.py`：按维度和权重折算百分制，报告各评委的分数、均值与分歧，并分开列出 `computed` 与 `judgment` 两部分的占比。
