# 数学与应用建模研究评审：正确性与研究价值

用于明确以数学或应用数学建模研究成果为交付目标的作品。数学方法是主干：问题形式化、假设与对象、推导和求解、独立核验及结论范围；应用学科补充对测量、机制和现实适用性的检查，不另造一套数学方法或通用投稿评分。共用证据、用途判断与评审行为边界见 [judging.md](judging.md)；研究方法、论文及共享模板见 [research-mode.md](../references/research-mode.md)。研究生竞赛仍按 [竞赛作品评审](contest-judging.md)，没有唯一答案或题目很难不改变交付用途。

研究论文使用同一评测入口和关键主张／根因记录，提供 `research_assessment`；不填竞赛七维表、奖项或百分制。以高水平原创研究为目标时，先区分复现、讲解、开发研究与原创研究。正确的已知定理讲解可以很有价值，却不能由此判为原创论文；证明未发现错误也不等于期刊已认可。

| 评价维度 | 需回答的问题 |
|---|---|
| `correctness` | 命题是否明确，前提是否足够，证明是否完整，计算证书是否表达了所声称的对象？核查范围与未核步骤分别写明。 |
| `novelty` | 相对最接近的已有研究，究竟新增什么？区分新证明、新机制、新事实、新方法与工程实现；已知工具在新对象上的应用须说明带来的知识增量。未知的新颖性不能凭“未找到”判定。 |
| `significance` | 结果解决了什么数学或应用问题，对领域认识有什么作用？有限计算覆盖更大、业务对象更换或样本更多不自动意味着更重要。 |
| `method_depth` | 方法是否解释结构，能否超越本例，是否有真正的技术障碍或可迁移洞见？复杂度与篇幅不代替深度。 |
| `exposition` | 定义、主结果、证明、图表和已有工作是否组织清楚，读者能否定位贡献和限制？不要求为了像论文而加图。 |
| `reproducibility` | 证明与必要计算能否独立检查，代码、输入、环境、证书与失败是否可追溯？运行通过不替代证明正确。 |

呈现顺序：目标标准 → 作品类型与当前质量判断 → 六项依据 → 距离目标的主要差距 → 最值得实施的修改。顶尖期刊没有通用的六维数字分数线；这里是审读框架，不是官方量表、录用预测或期刊认证。期刊指定后，再查它的具体范围和作者要求；格式与学术价值分开验收。

## 按研究主张补充检查

先从论文实际主张选择下列适用项，再核目标学科的对象、测量约定和已有结果；不要仅凭“经济学”“生物学”等标签整套套用。不同主张可以共存，逐项写明证据支持哪一层、哪些未检查；不适用项说明理由即可，不强制增加章节、数据或实验。沿用六维评价和现有 `critical_claims`／`issues`，具体依据写入相应 `evidence`，不新增一套分数或必填机器字段。

| 主张与任务 | 数学与应用证据应核什么 | 不可据此直接推出 |
|---|---|---|
| 解析命题、算法保证 | 对象、量词和前提；证明依赖、反例、精确答案或认证界；相对最近结果的增量 | 有限样例成立就是一般证明；应用问题必须另有现实样本才能接受纯数学命题 |
| 机制模型、数值模拟 | 状态与观测、量纲与尺度、守恒或平衡、初边条件、参数可辨识性、数值收敛；声称现实解释时再核独立观测与替代机制 | 方程可解、拟合好或网格收敛就证明现实机制；随机实验是所有机制模型的必需条件 |
| 经验描述、测量与新事实 | 构念如何变成变量、分析单位、分母与抽样框、测量误差、缺失与选择；不确定性及外推人群 | 局部样本代表总体；重要描述研究必须估计干预效应才有价值 |
| 预测与泛化 | 决策时可用信息、预测目标和跨度、实体／时间分割、泄漏、同信息基线、留出误差与不确定性 | 预测更准就识别因果或解释机制；同一数据重复调参仍是独立验证 |
| 因果与干预效果 | 干预、对照和估计对象；时间顺序、混杂、选择、识别前提、依从与干扰；支持范围与敏感性 | 相关、前后差异或模型情景就是干预效果；个体或局部效果就是群体推广后的效果 |
| 优化与决策建议 | 原单位目标、硬约束、整数与可行性、界／间隙、信息成本；参数、偏好和实际执行条件；与可行替代用途比较 | 求解器最优就是现实最优；代理分数或条件可行就是净收益更高或应当实施 |

学科条件用于发现遗漏，不能替代上述核验。例如物理／工程核材料和边界条件，生态核种群、观测尺度与采样过程，经济／管理核行为主体、激励、替代用途与竞争反馈，医学应用核目标人群、结局与适用性；仅检查实际主张涉及的条件。声称大规模部署、长期或跨人群适用时，继续追问反馈、资源约束和外推是否改变结论，不把任何一例的学科清单推广为全部研究的硬门。领域规范或事实未取到原文时保留待核；专业评审和期刊认可不能由本框架替代。相关方法按 [专业分工](../references/capabilities.md) 调用已有技能。

`critical_claims`只列实际论文主张；论文已说明经典或新颖性未建立时，不把“它是原创突破”这一未提出的命题塞入主张表并宣布论文被反驳。原创性与重要性差距保留在研究维度，数学有效性另判。原创性判断以文献与实际贡献的对照为依据，不因论文正文省去“本文非原创”等自评而扣分，也不以作者自我定级代替审查；证据等级与目标差距写入评审记录，核正文是否清楚陈述贡献、条件及局限。

每条记录仍写 `schema_version:2`、`paper`、评委身份、至少一条 `critical_claims` 与 `issues`，并加 `research_assessment` 对象：

- `problem`、`version`（实际稿件哈希）、`scope`（全文、证明或计算的真实检查范围）、`target_standard`、`overall_assessment`：非空文本。
- `work_type`：`reproduction`、`expository_note`、`original_research` 或 `development_study`；这是研究形式，不是质量排名。
- `criteria`：上表六项齐全，各含 `status:supported|refuted|unverified` 与非空 `evidence`，必要时 `issue_ids` 引用同记录根因。标签只覆盖证据中明确的判断，不认证整篇；“正确性有支持”和“新颖性被既有文献否定”可以同时成立。
- `major_gaps`、`actions`：文本列表，指向具体结果、证明或文献差距及修改价值。
- `novelty_search`：`completed` 布尔、`scope` 与 `sources` 文本列表。新颖性判为 `supported` 时须有真实完成的有范围检索及来源；字段校验不能认证检索充分或结论真新。

`python -m evals.aggregate --view=user research-review.json` 输出研究导向视图。评委身份、来源、稿件版本、关键主张和根因保持关联；多个评委分别呈现，不投票制造“顶刊级”。同篇不可把竞赛与研究量表混算，历史稿不补造已完成审读。
