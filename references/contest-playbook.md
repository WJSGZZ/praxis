# 竞赛类题目：怎样读题、选路线、避免丢分

适用于国赛、美赛、研究生数学建模等限时、开放、要交完整论文的题目。赛事规则每年会变：格式、人数、AI 披露、提交时限以当年官方文件为准，先核对再做。时间怎么排见 [solo-delivery.md](solo-delivery.md)，论文怎么写见 [writing.md](writing.md)。这里讲的是题目本身。

## 先给题目分类

题型不由题号决定，看题面的结构：

| 题面特征 | 常见结构 | 起点路线 | 常见的加分与丢分点 |
|---|---|---|---|
| 物理、工程过程，没有数据或只有少量参数 | 守恒方程、微分方程、热或流输运、控制 | 简化模型加解析基线；再做空间或动态模型；参数来自教材关联式与已发表测量 | 加分：解析界、参数依据、网格与参数敏感性。丢分：参数凭空设、只给一个数、约束量不收敛 |
| 资源、调度、选址、路径 | 线性或整数规划、网络、组合优化 | 手工可行解；精确求解并给界；与简单规则比较 | 加分：证明的界、小资金或小规模下的整数性检验。丢分：用启发式却无下界，目标权重随意 |
| 数据多、要预测或分类 | 回归、时间序列、机器学习 | 先做朴素和线性基线；留出集与滚动回测；再上复杂模型 | 加分：基线对比、误差区间、特征与机理解释。丢分：数据泄漏、只报训练精度、用深度网络处理几十个点 |
| 评价、排序、决策、政策 | 多目标、评价、博弈、系统动力学 | 先查支配关系；权重有依据；做权重与情景敏感性；给前沿 | 加分：说明偏好来源、排名稳定性。丢分：一组任意权重当结论 |
| 传播、扩散、网络 | 网络上的动力学、传染模型、图算法 | 舱室或网络模型；基本再生数；参数可辨识性检查 | 加分：可辨识性、情景。丢分：只拟合早期数据后外推峰值 |
| 环境、可持续、社会系统 | 多机制耦合、不确定性大 | 机制图加最小可检验模型；情景分析；写明模型边界 | 加分：诚实的不确定性、政策含义的限度。丢分：把情景说成预测 |

分类后，用 [structure-discovery.md](structure-discovery.md) 找结构，用 [path-search.md](path-search.md) 比较至少三条路线。标准题可以只写一行“为什么选它”。

## 按题型的最短阅读路径

不必读完全部参考。先读 [SKILL.md](../SKILL.md) 的“小任务直通”判断规模，再按题型走：

| 题型 | 先读 | 再用 |
|---|---|---|
| 物理、工程过程 | [domain-models.md](domain-models.md) 对应机制；[mathematical-reasoning.md](mathematical-reasoning.md) 的“数值收敛”与“阈值接近渐近值” | 正问题求解器（`solve_layered_diffusion`、`solve_diffusion`）加独立解（`layered_diffusion_laplace`、解析式）；`calibrate_curve`；`grid_convergence_index`；`sobol_convergence` |
| 规划、调度、路径 | [structure-discovery.md](structure-discovery.md)（全单模、松弛）；[model-library.md](model-library.md) 的规划与网络行 | `solve_lp`、`solve_milp`、`check_total_unimodularity`；先手工可行解、再给界 |
| 数据与预测 | [model-library.md](model-library.md) 的预测与回归行；[scientific-foundations.md](scientific-foundations.md) 第三节 | `ols_report`、`compare_models`、`backtest_baselines` |
| 评价、决策、政策 | [model-library.md](model-library.md) 的评价与多目标行 | `evaluate_alternatives`、`pareto_front`、`sobol_convergence` |
| 陌生或没有标准答案 | [path-search.md](path-search.md)、[research-mode.md](research-mode.md) | `route_graph`、`probe_structure`、`guess_sequence` |

## 题目要求逐项回答

- 把原文拆成编号任务 Q1、Q2……每个任务对应论文里的一个位置（需求对照表），交稿前逐项核对没有遗漏，也没有多答而漏答。
- 题面要求“写给某类读者的文字”（给用户的说明、给委员会的备忘录、给政府的建议）时，单独成页，不引用公式，只讲结论、依据、限度和行动。
- 没有数据的题，数据的缺口本身要回应：说明哪些量缺失、用什么依据暂代、哪些结论对它敏感、需要什么实验才能确认。

## 高分论文的共同特征

- 假设逐条给出理由，并说明哪个场景检验它；
- 有可证明或可独立核验的结论（界、守恒、极限情形），而不是只有一次仿真；
- 敏感性和稳健性有针对性：只扰动会改变建议的因素；
- 明确区分“计算得到”“推断”“假设”；结论强度与证据相称；
- 图表自己能讲清楚：图题写出论断，坐标含单位，不遮挡数据；
- 有自己的局限性与改进说明，但不堆砌自我批评；
- 摘要写问题、方法、定量结果和结论，不是目录。

## 更难的赛事（研究生赛、开放研究型题）

和本科赛的差别主要在开放度和深度：

- 题目往往没有现成模型，数据规模更大或来自真实科研场景；需要自己读文献、判断机制，再把机制翻译成数学结构（[structure-discovery.md](structure-discovery.md) 的机理对应表）；
- 常需要组合多个方法并说明连接：上游输出是下游什么输入、单位与尺度是否一致、误差怎样传递；
- 对验证的要求更高：独立方法、收敛研究、不确定性量化（[scientific-foundations.md](scientific-foundations.md)）；
- 评审更看重思路的新意和论证的严密：有没有发现题目没有明说的结构，有没有对自己的结论做证伪（[research-mode.md](research-mode.md)）；
- 计算量大时，要报告复杂度、运行时间和复现方式，并留出时间做稳健性复算。

## 常见丢分点

1. 没有逐项回答问题，或回答的是另一个问题；
2. 假设不合理又未检验；参数没有依据；
3. 结论说过头：把局部最优称全局最优，把情景称预测，把相关称因果；
4. 正文数字与结果文件不一致；图里的数字与正文不一致；
5. 图表看不懂（无单位、图例遮挡、颜色无意义）；
6. 参考文献不实或没读过却引用；AI 使用披露不真实；
7. 格式不符合当年规范（页数、字体要求、匿名、附件）；
8. 只有想法没有可复现的计算：没有代码、没有种子、没有数据来源。
