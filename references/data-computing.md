# 数据与计算能力

当任务进入实现、复算或数据质量问题时使用。任务含义与验证设计由 methods.md 提供；文件接收与运行命令见 automation.md，不另设推进流程。

## 输入到输出的契约

从原始输入用代码生成处理数据，记录单位、键、时间索引与缺失处理。模型读取什么、输出什么、顺序如何对应，都应可核对。更改编码、单位、聚合或缺失策略会改变答案时，在任务记录解释原因及影响，不把处理当无关机械步骤。

多表连接、实体别名或分类体系跨年变化时，先验证连接的语义和覆盖：列出未匹配及多重匹配，核对正结果记录是否恰好归属一次，并按关键年份／分组对账计数与总量。未匹配不等于观测为零；必要时保留未解析项或明确缩小分析范围，不能静默丢失。别名要有来源及时间范围，不能把历史上不同对象只因名字相近合并。聚合后总量相同也不证明细分类正确；相同奖项／事件可能有多名个人获奖，多个运动员记录也可能只是一项团体结果，应按原问题的计数单位检查，代理分配须说明和检验误差。

训练中学到的标准化、填补、特征选择等只对训练数据 fit；验证数据使用已学变换。交叉验证中，每个划分的变换也需重新在相应训练折拟合；时间和组边界由实际问题定义。可使用已有 scikit-learn Pipeline 将步骤结合，但 Pipeline 本身不保证划分、特征时点或调参没有泄漏。[scikit-learn 常见问题](https://scikit-learn.org/stable/common_pitfalls.html)

预测时须重放完整契约：截距、特征顺序、编码、训练所得变换、目标的逆变换与类别映射都跟模型一起保存。用一条可手算输入核对整个输入到输出链；不能只检查模型文件存在。固定训练数据、设置和随机性，只替换留出数据后重新拟合的模型、尺度或特征应保持不变，这是检查隐藏泄漏的一种办法。

## 模型比较与最终重训

先声明要推广到什么：同一对象的下一时刻、新对象，还是新地区。按该单位划分；同一人的多张图、同一路段的连续记录不能凭逐行随机划分支持对新人的或新路段的结论。时序特征只含预测起点已知的信息；中心平滑、完整序列分解、未来驱动变量要特别核对。真实未来驱动未知时，用情景或另一个预测模型，并传播其误差。

对每组超参数在相同划分上汇总所有验证折的预定指标，按任务确定按样本汇总还是各组等权，不挑“最好的一折”。选定后用全部开发训练数据重训完整处理链，保存本次重训的变换；不能拿某一折的模型配最后一折的尺度。变量筛选、分类阈值、集成权重、训练轮数，以及看过评估反馈后调整模型结构或概率校准方案，都属于模型选择。目标未进入数值拟合，不等于结构开发前未见其反馈。若反复查看测试结果决定它们，该集合已成为开发集，必须另留未参与选择的数据，或如实降低泛化结论。

组合方法先写清两个环节各自弥补的缺口，用相同信息、划分和总计算预算比较单一模型与组合。样本权重必须实际进入拟合或重采样；只计算一组权重不构成自适应集成。先在低成本候选中粗筛，再围绕有希望的范围细化，保留失败候选与停止依据。并行加速比较固定划分、初值和目标精度，计入预处理、搜索及最终重训的总时间；更换激活函数或训练目标是另一个模型比较。

分类或聚类的解释另查语义：簇编号可任意置换，不能按编号大小做回归或当作真实等级；与已知类别对照时用声明的匹配规则，并独立验证。软隶属度、投票比例与校准概率不同。总体分类准确率也不是某个对象的事件概率；即使两个模型分类全对，它们仍可能给出不同且未校准的概率。需要个体概率时核对概率输出、校准与对应群体，赔率按 p/(1-p) 计算，不能从准确率直接推导。除总体指标外，检查逐类召回、混淆方向和低置信样本；只有这种分析改变选型或建议时才扩展。原始编号、标签及由结果倒推的字段不能作为未解释的预测特征。

## 数值计算与失败

记录随机种子与实际环境。根据结构选择已有求解器，检查状态、可行性、容差与非有限值；改变初始点或精度不应被当成改变问题定义。连续模型看步长／收敛，离散模型保留整数约束，精确小例子可用 SymPy 对照数值结果。

把长期复用的处理与模型写成可审查源码，探索结果只有在同样输入下可重现后才进入正式输出。验收关注原题对应、信息边界、已知答案或独立约束，不只检查文件生成。

输出交给验证的是实际模型、处理说明、有效运行和结果；交给图表／写作的是经过检查的数值与限制，不是截屏或手抄数字。


连续过程的约束若要求全时间成立，离散采样通过不能自动证明采样点之间也可行。根据动力学选择事件检测、保守导数包络或更严格的数值认证；说明前提与求解误差余量。对分段控制在切换点分开处理，不跨越跳变插值。解析极限、独立积分器与守恒检查承担不同职责，不能把同一物理系数的两个积分器称为两套独立物理模型。
