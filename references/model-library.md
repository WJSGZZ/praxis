# 常用数学方法与工具：什么时候用、怎么验证

这是 methods.md 中“模型与验证一起选择”的条件参考。先看任务触发条件，再选工具；每种方法写明适用条件、可用工具、必须做的检查和常见误用。工具在插件里以 `praxis-tools` MCP 工具提供，也可在 Python 中直接调用 `modeling/` 模块，或用 `python -m scripts.mcp_server --call 工具名 '参数JSON'` 命令行调用（`--list` 列出工具及字段，`--describe 工具名` 给完整输入格式；在仓库根目录运行，或设置 `PYTHONPATH` 指向它）。工具只负责计算，不判断模型是否适合问题。

| 任务触发条件 | 方法与工具 | 必须的检查 | 常见误用 |
|---|---|---|---|
| 有目标和硬约束的分配、调度、选址 | 线性／整数规划：`solve_lp`（给对偶间隙证书；支持 ≤、≥、= 三类行，影子价格 `ineq_duals`、`ge_duals` 为右端项增加一个单位时最优目标的变化）、`solve_milp`（给界与间隙） | 手工可行解先行；LP 看间隙，MILP 看 `proved_optimal` 与 `mip_gap`；约束量纲逐条核对 | 把整数解四舍五入；把求解成功当模型正确；大 M 取值过大造成数值问题 |
| 路径、流量、连通与最小代价 | 网络：`shortest_path`、`max_flow`（同时给最小割）、`minimum_spanning_tree`；一对一指派 `solve_assignment`；往返路线 `solve_tsp`（启发式，附 1-树下界与差距） | 最大流等于最小割容量；路径长度手算一遍；负权边先另行处理 | 无向／有向混用；容量与流量单位不一致。`solve_tsp` 给的是可行路线加下界，差距不为零就不称最优 |
| 多方案比较，指标可量化 | `ahp_weights`（一致性比 CR）、`entropy_weights`、`evaluate_alternatives`（TOPSIS 与权重扰动稳定性） | 先查支配关系；CR<0.1 只是筛查约定；权重变化下的排名是否翻转 | 熵权当“重要性”（它只反映离散程度）；用同一批数据既定权重又当证据；指标重复计入 |
| 预测未来数值 | `backtest_baselines`（朴素、季节朴素、漂移、线性趋势、Holt 的滚动起点比较）；`gm11_forecast`（短正序列） | 候选模型必须胜过最好的基线；最终留出段不参与选型；GM(1,1) 报 C、P 等级 | 在几个点上拟合就外推；用训练误差说明预测能力；GM(1,1) 用于有明显波动或季节的数据 |
| 传染、扩散、种群等随时间连续变化 | 常微分方程：`sir_simulate`、`sir_fit`（报可辨识性）；一般模型用 `scipy.integrate.solve_ivp` | 守恒量；终态与解析关系（SIR 终态规模 z=1−exp(−R0 z)）；只有感染数据时 β、γ 强相关要如实报告（`sir_fit` 的判据：雅可比条件数大于 1e6 或参数相关系数绝对值大于 0.98；它的标准误是模型正确、噪声独立时的局部值，对平滑数据会小得不真实；初值取数据首项、康复者取 0；已附终态规模） | 只拟合早期数据后外推峰值；把拟合优度当机制证据 |
| 等待、服务、容量 | 排队：`queue_mmc`（M/M/c 闭式）；到达或服务不符合假设时用离散事件仿真 | 利用率<1；Little 公式 L=λW；仿真给重复次数与置信区间 | 对非泊松到达直接套 M/M/c |
| 参数或假设不确定，影响结论 | 范围分析与全局敏感性：`sobol_sensitivity`（算术表达式，独立均匀输入） | 已知效应的小例子；样本量收敛；区间随结论改变否 | 敏感性当因果；把选定的范围说成概率分布 |
| 回归、分类、聚类、降维 | `ols_report`（置信区间与诊断：正态、异方差、自相关、共线性、强影响点）、`compare_models`（基线、线性、岭回归、梯度提升的交叉验证比较，须胜过基线超过一个标准误才算有改进）；statsmodels、scikit-learn；先用可解释基线 | 分组／时间留出；预处理只用训练信息；残差与多重共线性 | 数据泄漏；用测试集调参；把关联写成因果 |
| 数据量较大、关系非线性、可预测性是目标 | 树模型与梯度提升（scikit-learn），配合置换重要性或 SHAP 解释；必须与线性或朴素基线比较 | 按时间或分组留出；调参只用训练折；报告相对基线的提升与区间 | 只报训练精度；黑箱结论没有机理解释；数据泄漏 |
| 仿真或物理模型很慢，需要大量调用 | 代理模型（高斯过程、多项式混沌、神经网络），用少量设计点训练，再做敏感性或优化 | 留出点上的代理误差；最优点回到真实模型复核 | 代理误差未量化就用于优化；在训练范围外外推 |
| 序贯决策、状态随动作变化 | 先写出能求解的基线（动态规划、模型预测控制、贪心）；强化学习只在状态空间大、模型难写时补充 | 与基线比较累计回报；多个随机种子；说明奖励设计与训练设置 | 强化学习不与基线比较；单个种子；奖励函数针对评分调参 |
| 时间序列有多个驱动变量、数据较长 | 状态空间与卡尔曼滤波：`kalman_filter`（线性高斯，给对数似然）、statsmodels；LSTM、Transformer 等序列网络只在数据足够多时作为候选，并与季节朴素、ARIMA 比较 | 滚动起点回测；多步预测单独评价；报告相对基线的误差 | 样本几十个点却上深度网络；只看一步预测 |
| 无标签数据、找群体或异常 | 聚类（k-means、高斯混合、DBSCAN/HDBSCAN）、孤立森林；先标准化并降维可视化 | 聚类数的判据（轮廓系数、稳定性）；换种子与方法后分组是否一致 | 把聚类结果直接当类别含义；不检验稳定性 |
| 参数不确定、希望得到后验区间 | 贝叶斯推断与 MCMC（PyMC、emcee）；贝叶斯优化（Optuna）用于目标评估很贵的调参 | 收敛诊断（R-hat、有效样本数）；先验敏感性；后验预测检验 | 先验随意；不看收敛 |
| 想从数据里找公式或微分方程 | 符号回归（PySR）、稀疏辨识 SINDy（PySINDy）；候选模型再用机理检查量纲与极限行为 | 留出数据误差；量纲一致；噪声下是否稳定 | 把拟合出的复杂式子当规律；不检验量纲 |
| 物理定律已知但数据稀少 | 物理信息神经网络、神经常微分方程作为补充；先用经典数值解作基线 | 与数值解或解析解比较；多个初值；训练是否收敛 | 不与经典求解器比较；只展示拟合曲线 |
| 图或网络数据（社交、交通、电网） | 图算法与社区发现（networkx）；图嵌入、图神经网络只在节点属性丰富时使用 | 与简单中心性或度分布基线比较；留出节点或边 | 没有基线的图神经网络；训练测试节点泄漏 |
| 图像、文本、音频类赛题 | 先用经典处理（scikit-image、OpenCV、TF-IDF）建基线；预训练模型提特征再接简单分类器 | 人工抽查样本；留出集；说明预训练模型来源和许可 | 把大模型输出当事实；训练集和测试集同源重复 |
| 约束组合优化（排班、路径、分配） | 精确求解优先：OR-Tools CP-SAT、MILP；多目标进化算法（pymoo 的 NSGA-II）用于非线性或黑箱目标 | 精确解的间隙或上界；进化算法多次运行的前沿分布 | 能精确求解却用元启发式；没有上界或下界 |
| 因果结论或政策评估 | 双重差分、倾向得分匹配、工具变量、合成控制（DoWhy、statsmodels）；先写明识别假设 | 平行趋势或平衡性检验；安慰剂检验；敏感性分析 | 把相关性写成因果；不检验识别假设 |
| 生存、寿命、故障时间 | 生存分析（lifelines）：Kaplan–Meier、Cox 比例风险 | 比例风险假设检验；删失数据处理 | 忽略删失观测 |
| 非线性优化、控制 | `scipy.optimize` 多起点；分段常数控制族；SQP | 报告是局部最优；与更宽的族比较；上界或下界给出差距 | 单起点结果当全局最优 |
| 多目标折中、目标优先级 | 加权、ε 约束或目标规划（偏差变量）；`pareto_front` 找非支配解，画前沿而不是只给一个权重 | 权重或优先级有依据并做范围分析；前沿上标出推荐点及理由 | 一组任意权重当作“最优” |
| 状态随阶段转移、随机状态链 | 马尔可夫链：`markov_stationary`（稳态分布，报告是否不可约）、`markov_absorption`（吸收概率与期望步数）；动态规划（逐段最优，反向递推） | 转移概率有数据或来源；用模拟或封闭解互证；稳态结果是否荒谬 | 把非齐次过程当齐次；稳态解不检查是否与现实矛盾 |
| 双方博弈、策略对抗 | 矩阵博弈：`matrix_game`（线性规划求混合策略与值，并判断鞍点） | 收益矩阵来源；纯策略鞍点先检查；对支付扰动做敏感性 | 把非零和问题当零和；忽略对方的约束 |
| 库存、订货、批量 | `eoq`（含计划缺货的扩展）；随机需求用 `newsvendor`（正态需求的临界分位）或仿真 | 单位一致；对需求与成本范围做敏感性；封闭解与仿真互证 | 需求当确定量却没有说明 |
| 模糊概念、定性评价 | 模糊综合评价、层次分析（`ahp_weights`）；隶属函数要说明选择依据 | 隶属函数或权重换一种设定后排序是否稳定 | 隶属函数随意给定；用复杂性代替依据 |
| 多指标降维、分类、归并 | 主成分、因子分析、聚类、判别；标准化后再做；用解释方差、轮廓系数或留出集检验 | 成分含义能解释；聚类数的选择有判据；训练、检验分开 | 把降维结果当结论；不标准化量纲不同的指标 |
| 组间差异、因素影响 | 方差分析、回归（statsmodels）；先看分布与方差齐性 | 假设检验与效应量并报；多重比较校正 | 只报 p 值；样本很小时下强结论 |
| 小样本、变量多且相关 | 偏最小二乘回归、岭回归；交叉验证选成分数 | 留出或交叉验证误差；系数稳定性 | 用训练误差评价；变量比样本多仍用普通最小二乘 |
| 离散阶段的递推与稳态 | 差分方程模型：先求平衡点与稳定性，再数值迭代；与连续模型比较 | 平衡点的稳定性条件；步长改变后结论是否不变 | 只迭代不分析稳定性 |
| 全局搜索、组合优化（精确法太慢时） | 模拟退火、遗传算法、粒子群等元启发式；固定种子、多次运行报告分布，与下界或简单规则比较 | 多次运行的最优值分布；与基线、下界的差距 | 单次运行当最优；参数调到只对一道题有效 |
| 热、扩散、波动在空间中传播，要解偏微分方程 | 一维热/扩散方程：`solve_diffusion`（有限体积，θ 格式，给能量收支；`points` 返回指定位置的温度）；更复杂的几何用有限体积或有限元并保持守恒 | 与解析解比较并报告观测收敛阶；能量收支残差；边界条件的物理来源 | 网格不加密就报结果；Dirichlet 与 Robin 边界混用不说明；约束量依赖网格（点源单元）却当作收敛结果 |
| 有风险的收益、要控制尾部损失 | 情景下的最小 CVaR 组合：`cvar_portfolio`（线性规划）；方差类风险只在分布近似正态时使用 | 情景数与尾部分位数的关系；结果对情景抽样的稳定性；与等权基线比较 | 把情景当预测；用历史情景外推极端风险；只报期望收益 |
| 动力系统有多个平衡点、关心稳定性 | `equilibria`（多起点求根并按 Jacobian 特征值分类）；线性化不能判定时用 Lyapunov 函数或数值积分 | 平衡点是否遗漏（换起点和范围）；非双曲情形不下结论；与轨迹仿真互证 | 把线性化结论用于非双曲点；只看一个初值 |
| 推导与量纲检查 | SymPy 符号化简与单位检查 | 代入数值反验；量纲一致 | 软件化简出的式子不核对适用条件 |

这些是条件分支，不是必经清单。一个任务通常只用其中一两项；任何方法都先说明它回答哪项任务，再说明验证。

## Python 够用吗

数值计算、统计、优化、网络、符号推导、微分方程与出图，NumPy、SciPy、pandas、statsmodels、scikit-learn、networkx、SymPy 与 Matplotlib 覆盖了绝大多数建模任务，可以替代 MATLAB 与 R 的常规用法。只有出现具体缺口时才考虑别的工具：框图式动态仿真、专门的偏微分方程求解器、某些 R 独有的统计包，或商业求解器（Gurobi、Lingo）才能处理的超大规模整数规划。此时先写明缺口与用途，核验来源与许可，再在任务记录里保留输入、命令和输出；未经需要不安装大型工具。HiGHS 已能处理常见规模的 LP／MILP，路径与排班类问题规模更大时再核验 OR-Tools。
