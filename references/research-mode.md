# 研究模式：没有标准答案时怎样工作

题目没有答案可对、结论要靠自己建立证据时读。这类问题包括：研究型建模（答案不唯一）、开放问题（没人知道答案）、以及“有没有更好的办法”。目标不是硬凑一个答案，而是产出**可检验的东西**，并如实标注每一项的把握程度。

## 题目的四个层次

| 层次 | 例子 | 怎样判断做得好 |
|---|---|---|
| 竞赛题 | 有官方标准解法的往年题 | 建模、算法、计算、验证、写作；与标准答案和优秀论文对照 |
| 难度更高的竞赛题 | 研究生赛、没有见过的陌生题、跨学科题 | 能否迁移到陌生结构；能否在没有现成模型时找到路线 |
| 研究型问题 | 答案不唯一，评价看思路、假设、数学结构、验证 | 路线质量、假设是否可检验、验证程度、是否承认局限 |
| 开放问题 | 没有已知答案 | 是否提出了新路线、发现新结构、得到可验证的中间结论、缩小问题范围、找到反例或新猜想 |

层次越往后，整体质量越不能只靠一个标准答案评价；具体命题、证明和计算仍须判断对错。评价要区分**证据类型、覆盖范围和研究增量**。

## 能交付什么

没有标准答案时，下面这些可以成为有价值的产出，前提是各自带证据，并回应本次研究目标；完成一项简单复现不自动代表深度目标已完成：

- **可验证的结论**：一个界、一个恒等式、一个算法保证、一个已证明的特例。
- **反例**：证明某个看似合理的命题不成立。
- **缩小范围**：证明答案必然落在某个区间、某个集合里。
- **归约**：证明这个问题等价于或不难于一个已知问题。
- **猜想**：由数据或小例子归纳出的规律，标明检验到多大规模。
- **改进**：对已知方法的可量化改进，附比较。
- **计算结果表**：由可复现的计算得到的数据，供后续人使用。

开工说明相对已知基线的具体缺口，区分初步复现、已核验的增量和尚未确认的原创性。优先追求能改变判断的界、归约、机制或算法保证；不是只选最容易算完的特例。计算用时、整个研究投入和论文篇幅分别记录，不能互相替代。有限计算如能支持一个覆盖无限对象的严格归约，应明确前提与余下对象；极小的未覆盖密度也不能读成零。

继续投入前检查是否有能获得新证据的具体行动。若已经证明当前路线存在结构障碍，单纯增加枚举规模不会消除它，应保留有效结果、解释障碍并按原预算停止或转向。难题暂未解不等于整条路线无价值；也不能凭“很有希望”突破预算。版式专业不等于研究达到顶尖水平，未经文献与质量评审不作这种认定。

## 研究论文的质量目标

默认按面向专业数学研究者、可供严格同行审查的质量组织论文；用户以顶级期刊为目标时，研究深度不能在“专业排版、计算跑通”处止步。分别核查问题价值、文献定位、可明确陈述的贡献、证明完整性、计算可靠性与表达。复现案例可以展示方法，但不能靠扩充文字或重排版升级为原创投稿成果。原创性待确认时，下一研究行动应针对具体文献差距或数学缺口；期刊是否适合、贡献是否足够，另行判断。

引言说明已知什么、缺什么、本稿具体解决什么；定理保留全部前提，证明明确依赖，计算命题交代有限覆盖与独立检查。正文以数学内容为主，开发路线和验收日志放复现材料，必要局限就近说明。通用研究稿使用 `templates/research-style.tex` 和 `templates/research-paper.tex`：AMS `amsart`、A4、11pt Latin Modern正文与数学、30mm边距，共享定理／证明与图注样式。生成源内嵌 `scripts.paper_template.style_block("research")`，成稿执行 `python -m scripts.paper_template paper.tex --contest research`；常见直接字体／版面覆盖会被拒绝。AMS正文页采用单独的短页眉标题，避免完整题名与页码相撞；主标题、作者、日期、MSC分类、关键词及章节按实际内容提供，目录和图不强制；匿名或无已确认作者时不造名字。只有确定目标期刊后才采用其投稿模板，不把某一种字体、页数或章节配置当成所有数学期刊的统一要求。

图按论证需要选择：构造或反例图应帮助检查证明，计算图应揭示表格难以直接表达的结构。没有这种价值就不加；有必要的解释也不能因稿件较短而省略。图内区分离散点、连续曲线、插值和阶梯；图注的左右／上下指向须与实际渲染一致。将图、算例、数值表与摘要对应到有效证据，最终查看每页实际成品。页数、图数与期刊档次分别判断，不设置装饰图或凑篇幅指标。

## 实验数学的循环

1. **算小例子**：把问题的最小规模版本做成可穷举或可精确求解的程序，得到一批数据。
2. **猜规律**：对序列用 `guess_sequence`（线性递推与多项式，精确有理数；`holdout` 留出最后几项检验猜测，方程数远多于未知数才算有冗余）；对数值常数用 `find_relation`（PSLQ 整数关系）；对函数关系用 `probe_structure` 判断单调、凸、对称、幂律。
3. **检验猜想**：在更大规模或更高精度上检验：`test_conjecture`（等式或不等式，随机点）、`modeling.experiment.test_conjecture`（mpmath 高精度）。不要拿拟合所用的数据当检验数据。
4. **找反例**：`find_counterexample` 对整数域做穷举（总数不超过 `exhaustive_limit`，默认 20 万；此时“无反例”是对该域的证明，输出 `proved_for_domain`），更大的域只是抽样；穷举发现反例时 `cases` 记录已检查数、`exhaustive` 为真（表示采用穷举策略，并非已完成全域）。只有全部求值成功且无反例时才能给出域内证明；异常与非有限结果记录为 `evaluation_errors`，不算反例。命令行里只能写算术、比较和 `isprime`、`gcd` 等；要检验序列上的断言（如递推）用 `check_recurrence` 或自己写脚本。发现反例后，在 `shrink_budget`（默认 1000 次求值）内向简单形式缩小，再据此修改猜想；检查 `shrinking.status`，预算耗尽仍保留已验证反例，不宣称全局最小。
5. **尝试证明**：给出证明草稿，标明哪些步骤已严格、哪些只是论证。能用交换论证、归纳、守恒、单调性、对偶的先试。
6. **记录**：每个结论按下面的把握阶梯标注，并保留失败的尝试和被排除的方向（`route_graph` 与 `lesson_add`）。

## 把握阶梯（每条结论必须标一级）

| 等级 | 含义 | 允许怎样表述 |
|---|---|---|
| 已观察 | 在若干例子中看到 | “在……例子中观察到” |
| 已猜想 | 归纳出规律但无检验 | “猜想”，不写成事实 |
| 已检验到规模 N | 区分全域穷举与随机抽样，记录覆盖范围、样本数和求值失败 | 只有全域穷举且每项精确核对成功时才写“在该有限域成立”；抽样只能写“已检查的样本中未发现反例”，不能推广到未覆盖范围 |
| 已证明（草稿） | 有论证，但没有逐步核对 | “证明思路如下，尚未完全核对” |
| 已证明（有限核对） | 严格的框架加有限项的精确核对（见下） | “定理：由……阶数上界与前 N 项核对” |
| 已证明（完整） | 每一步都核对过，或有机器验证 | “定理” |
| 已推翻 | 找到反例 | 给出反例 |

没有机器验证或独立核对的证明不称“定理”。数值上“检验到很大规模”也不是证明。

**线性递推的有限核对模板**（严格）：若已知序列满足某个阶数不超过 N 的常系数线性递推（例如它等于 uᵀMⁿv，M 为 N×N 矩阵，由 Cayley–Hamilton 得阶数不超过 N），候选递推的阶数为 d，设该递推为 P(E)a=0（E 为移位算子），候选递推为 Q(E)a，则差序列 b=Q(E)a 也满足 P(E)b=Q(E)P(E)a=0（多项式算子可交换），即 b 满足同一个阶数不超过 N 的首一递推；这样的序列只要前 N 项为零就恒为零。所以从头开始连续 N 条方程成立（数据里的 N+d 项）就是完整证明。`check_recurrence` 的 `order_bound` 参数给出所需方程数并判断是否已够。例：3×2n 多米诺铺法数用 8 个列状态的转移矩阵，N=8，候选 aₙ=4aₙ₋₁−aₙ₋₂，d=2，前 8 条方程（a(0) 到 a(9) 共 10 项）成立即为完整证明。这里的 N 本身要有依据（如转移矩阵的大小），否则只是证据。

## 与路线记录的对应

`route_graph` 的 `keep_result` 的 `status` 可以直接用阶梯的词：`observed`、`conjectured`、`checked_to_N`、`proved_sketch`、`proved_finite_check`、`proved`、`refuted`（也接受 `derived`、`checked` 等证据等级）。研究型问题通常用 `mode: "exploratory"`；备选路线若显然站不住，直接 `kill` 并写一行原因。

## 文献与新颖性

- 声称“新”之前先检索：用 `search_literature` 查标题和关键词，用 `find_open_access` 读全文。记录检索词和日期；检索不到只说明“本次未检到”，不能说“不存在”。
- 已知结果不要当新结果。核对自己的“新结论”是否其实是教材或综述里的标准结论。
- 引用时区分原文给出的结论、原文的数值证据、自己的推论。

## 诚实边界

- 只有完整命题已被证明、所有关键前提和覆盖范围均成立且经过独立核对，才能声称解决对应问题。局部定理、有限证书或验证器通过不能替代对一般命题的证明；机器检查还须核对其编码的命题是否就是所声称的命题。
- 不用“标准答案”的叙述方式写没有标准答案的结果。
- 失败也是结果：写明试过什么、卡在哪里、排除了哪些方向。
- 计算得到的常数、关系（PSLQ 等）只是线索，要给出解析证明或高精度独立验证再用。

## 评价（用于自评和盲测）

没有标准答案时，先核查命题、证明和计算的正确性，再用下面的问题评价研究价值：

- 是否提出了至少一个新的、可检验的路线或猜想？
- 每个结论的把握等级是否标注并与证据相符？
- 是否有反例搜索，找到的反例是否被用来修正猜想？
- 中间结果能否被他人复现（脚本、种子、数据）？
- 是否把已知结果误当新结果？
- 失败和被排除的方向是否留下记录？
