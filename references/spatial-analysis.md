# 空间分析专业参考

本参考处理空间度量和空间关系如何改变答案。按任务风险取用相关检查；若空间信息只用于展示，不必人为增加GIS流水线。

## 1. 数据与基准

记录源文件／图层、版本或获取日期、授权来源、记录数、几何列、稳定ID及其产生方式、重复／空ID、空／空几何、有效性、精度和单位。对栅格还记波段含义、尺度因子、日期、像元大小、仿射变换、有效掩码及nodata。

分别确认水平CRS、垂直基准及高程单位；涉及动态基准时记录坐标历元。地理坐标核CRS定义、区域适用范围、轴序、单位和变换管线；已知单位、共用原点／轴和比例的本地直角坐标可直接计算平面距离，不要求EPSG编号。来源未给所需框架、单位或基准时，不以数值范围推断；只做不依赖未知基准的结构检查和明确条件下的敏感性分析，并说明需何来源信息才能继续。赋CRS标签不等于坐标变换：`set_crs`标识已有坐标，`to_crs`才转换它们。

GeoPandas与Shapely按平面坐标计算，Z通常不进入距离／拓扑判断。角度坐标不能直接作米制距离、缓冲或面积；投影坐标也须检查轴单位和变形是否适合目标。Web Mercator适于网络底图显示，不是通用距离／面积基准。小区域可用适合该区的投影；跨区或全局地表距离采用椭球测地线，例如PyProj的Geod或GeographicLib。坐标数组接口显式处理轴序，避免权威CRS轴定义与常见x/y顺序不一致。日期、定位误差和坐标精度要与阈值比较；结果贴近误差范围时报告边界不确定，而不是输出虚假的精确分类。

## 2. 矢量操作

把问题写成具体几何量或谓词：点到点、点到线、面重叠、边界是否计入、最大距离是否含等号。点落在多边形边界时，`within`通常排除，而`covers`可包含；按业务语义选择并记录。空间索引只加速候选搜索，不替代精确谓词。

最近邻查询可能有多个等距结果，空间连接也可能一对多或多对多。声明预期基数和破同分规则，保留匹配表，再核对匹配数、唯一键、未匹配对象和连接前后行数；不能把任意首条当唯一最近。GeoPandas `sjoin_nearest` 对等距最近对象可返回多条，且其距离在经纬度CRS下会不准确，故需使用适当平面CRS。点数据的欧氏邻居可复用现有SciPy KDTree；给定半径需要完整候选时用半径查询并明确单位、精确或近似参数、并列处理与输出排序。硬阈值资格不要直接接受近似检索；SciPy半径查询用eps=0，并在边界上复核实际距离。

修复无效几何、精度吸附或切分跨投影边界对象会改变表示。比较操作前后几何类型、组件数量、面积／长度、覆盖关系和ID对应，记录是否丢弃或拆分对象。面积比较应在合适投影或测地方法中完成；小碎片不自动视为噪声。线段在源投影内被视为直线，跨经度断裂或投影边界时需按地理形状处理并复核结果。

## 3. 栅格对齐与聚合

逐项比较CRS、像元大小、仿射变换、原点／像元注册、范围、行列数、波段语义和时间戳。数组shape一致不能证明网格相同。指定参考网格和重投影／重采样方向；离散类别、标签或掩码用最近邻，或按明确的多数／面积比例规则聚合，以免生成不存在的类别，连续观测按数据支持与分析目标选择插值核。重采样后检查数值范围、单位、有效像元数及总量／均值等与问题相关的守恒指标。

按数据源定义处理nodata，不能假定0代表缺测。传播云、阴影、饱和、边界外及无观测掩码；计算差值／比值时先防止整数溢出或nodata进入运算。汇总面积或覆盖率时交代像元面积是否相同、边界像元权重以及掩码分母。高程和水平距离结合时统一垂直单位及基准，不能因两者数值都是米就视为同一基准。

## 4. 覆盖、分配与可达

将覆盖规则形式化为距离、阈值、边界约定、需求／设施ID和候选边表。若位置误差有界或随机，分别区分必然可达、可能可达和按名义位置可达；误差半径需换算到相同地面单位。保留全部候选与未匹配需求，记录筛选标准、来源日期和约束。道路／河网实际可达需沿相应网络计算并处理方向、阻隔、速度或通行规则；直线缓冲或欧氏最近仅是代理量。

容量约束属于分配问题：总供给不少于总需求仅是必要条件，局部可达集合仍可能供给不足。把空间匹配构造成现有LP/MILP、流或路径工具输入，在求解后逐项复算服务、容量、未满足量和原始成本。对候选方案也检查坐标误差、阈值临界边以及局部设施故障；地图上相近不构成可行或最优证明。

## 5. 评估与核验

空间相关使随机拆分可能让相邻地点跨越训练／验证集，产生过乐观误差。预测验证按部署目标采用空间分块、缓冲隔离或时空留出，说明块大小、间隙和抽样覆盖；这些方法不自动解决混杂或因果识别。空间统计推断和干预效应交相应专业技能。

按主要结论选择独立手算、解析小例或另一种实现核对坐标转换、边界距离／面积、空间匹配数或栅格掩码；仅审来源元信息不必强行另算坐标。检查单位换算、等号边界、缺测点和重复ID。地理地图按读图需要标比例／方向和量纲；米制平面图保持等比例坐标，点密度或聚合图注明聚合单位及色标；显示范围、裁剪、插值和隐私泛化均可改变读者判断。可视化用于检查和沟通，不替代数值证据、选址审批或工程勘察。

## 6. 工具选择和适用边界

优先使用项目已有SciPy、NetworkX及数据栈。GeoPandas/Shapely适合常见矢量表与拓扑；PyProj用于CRS和测地转换；Rasterio适合栅格读写、掩码与网格变换。它们是可选依赖，不因本参考而默认安装或锁定版本。首次确需执行时检查可用版本、原生库兼容性、数据驱动及输出复读；资源不足时保留计算定义和可复核手算，不宣称执行完成。

本流程不实现通用CFD、水动力或工程安全认证，也不把空间聚集图解释为因果效应。需要机制和边界条件的物理模型交动力学／领域建模；出行与网络路线交网络优化；决策目标不清交模型设计；独立验证交核验技能。
