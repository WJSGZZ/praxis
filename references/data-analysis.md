# 数据理解、探索与连接判断

本参考负责数据测量与探索的专业判断，由 [praxis-data-analysis](../skills/praxis-data-analysis/SKILL.md)按需调用。文件接收、变换与运行契约仍归 [data-computing.md](data-computing.md)／[automation.md](automation.md)，路线及条件归 [methods.md](methods.md)。数据分析不是先画一套图再找故事；它应决定哪些问题能回答、哪个处理选择会改变答案、什么还需要来源或观测。

## 从研究问题确定观察和测量契约

先将目标量写成可计算定义，说明目标群体、时期、空间范围和分母。逐项核对原件／字典／来源，不从列名自动补充以下含义：

| 需要确认的事项 | 会改变哪个判断 | 证据或缺口 |
|---|---|---|
| 每行与唯一键代表事件、实体、实体×时点或测量 | 重复、聚合、分母、连接基数 | 键定义／生成机制及重复原因 |
| 独立样本、重复测量和层级 | 有效样本量、区间与评价划分 | 采样／配对／组／批次来源 |
| 变量单位、比例、精度及派生公式 | 换算、比较、加总、轴与结论尺度 | 字典、测量设备或推导 |
| 抽样框、入选与观测概率 | 群体推广、权重和选择偏差 | 纳入／失访条件和覆盖 |
| 缺失编码、结构不适用、删失和检测限 | 是否可填补、是否能计零、结果似然 | 原始码与测量约定 |
| 时间、发布时点、类别／实体时效 | 时序连接、训练信息与跨期比较 | 原始日历与版本 |

没有定义时标为待确认。可以先给已核的尺寸、解析与缺失计数，不能把这种结构结果升级为语义有效。分别保留“原始值是什么”和“派生变量如何解释”；只读原件、派生数据另存按执行参考，不在这里另规定目录。

标签只在部分对象上完成时，保留全体、已裁定和未裁定的分母、进入裁定的机制，以及观测／接收／标签完成时点。令 `V=1` 表示已裁定，`Y=1` 表示目标阳性，则 `pV=P(Y=1|X,V=1)`、`pAll=P(Y=1|X)` 和 `pU=P(Y=1|X,V=0)` 是不同目标。未裁定不是负例；在已裁定样本上拟合得到的概率也不能仅改字段名就当成未裁定概率。选择运输与校准的条件见 [statistical-analysis.md](statistical-analysis.md#概率目标与选择运输)。

图片数据沿用同一测量契约：记录原图、同一拍摄／对象／事件的源家族、标签来源与完成时间、裁剪和增强的派生关系。图片数、独立事件数与真实对象数分别计数；信息不足的图片可为待判定，不能因目标不可见就补负标签。像素测量、ROI与阈值选择交 [image-analysis.md](image-analysis.md)，图像特征的预测划分交 [machine-learning.md](machine-learning.md)，地理坐标和栅格对齐交 [spatial-analysis.md](spatial-analysis.md)。

## 覆盖与探索先检验解释是否站得住

根据问题检查总体及关键组／时间的覆盖、独立实体数、重复结构、缺失比例与取值域。比较均值／SD和中位数／IQR／MAD，查看有序变化、边界、离散点、异常影响及同分母的组差异。异常标记是调查起点；有效极端观察应保留，删除需具体测量错误或预定排除规则，并核对结果影响。

缺失关联图或组间缺失差异只能提出候选机制。MCAR／MAR／MNAR是针对变量和分析模型的条件，不能凭检验不显著认证；结构性缺失和低于检测限不应自动纳入通用均值填补。重要结论比较可论证的缺失／删失处理，说明还无法排除的方向。

有界扫描须说明扫描行／字节、是否前缀、截断、抽样种子／规则及哪些组未覆盖。均匀抽样、分层抽样、按独立实体抽样回答不同问题；文件按结果／日期排序时，前若干行不能外推总体。只看随机总体样本可能漏稀有类，应额外查看关键稀有组；额外查看与总体统计估计分开，并保留各自权重。

## 多表连接是测量的一部分

每次连接先说明双方键的科学身份、时间范围和预期 `one_to_one`／`many_to_one`／`one_to_many`／`many_to_many`。实体别名、历史类别、单位换算和未知键分别处理，不用模糊名字相似度自动完成身份认定。

已有 `audit_join(left, right, on, how, relationship, null_policy, max_output_rows)`接受JSON记录数组，使用Pandas基数验证，报告aggregate覆盖与行膨胀，不返回拼接后的原始记录。默认空键拒绝；选择 `drop` 会改变覆盖，选择 `match` 采用Pandas空键相互匹配语义，二者都须给科学理由。未知但非空的键与空键不同，未匹配计数仍应追查。工具确认的是声明基数与实现，不确认键实际指同一对象。

先用该工具或 `DataFrame.merge(validate=..., indicator=True)`拒绝不合法基数，再检查：双方未匹配／多重匹配、原实体数与输出记录数、关键时期／组的覆盖、计数和加权总量。多对多输出可能是乘积膨胀；即使总和相同，也可能是组别错配。确需分配共享事件时，先定义分配单位／权重，再按该定义核守恒，不能以人数代事件数或把未匹配观测设为零。

对复杂表契约，Pandera `DataFrameSchema`可表达范围／枚举／联合unique及自定义关系。需要唯一表头须显式 `unique_column_names=True`；`Check`默认忽略NaN，与列 `nullable` 不是同一约束。只读审计默认不启用coerce、parser、strict-filter或drop-invalid；校验抽样不认证全表。Pandera是可选适配路线，不因文档存在就宣称已安装或认证。

## 预处理如何影响答案

清洗、聚合、类别合并、编码、尺度转换、填补和筛选分别给含义、规则、输入版本及影响：原观察数／实体数、被排除范围、目标群体变化和关键估计变化。需要单位换算时保留原单位与系数，以手算边界核换算；标准化后不保留原尺度含义的模型系数不能直接解释为单位效应。

训练中学习的处理与选择统一按data-computing.md，只在相应训练折fit；泄漏检查必须涵盖时间、组与结果派生字段。更换最终留出目标不能改变先前训练所得的尺度／词典／模型，是相称的反向检查之一。没有预测用途的描述性处理也须明确其分析群体，不借训练术语掩盖选择。

## 最小交付与失败返回

围绕本次问题给：可回答量与契约、实际覆盖／探索证据、已核连接和处理、敏感性、未知事项与影响。已证实的结构、来源支持的含义、条件推断分别表达。小请求不必填满上述所有表项。

计数或单位不对，修派生链并复核关联结果；目标或测量定义不成立回praxis-model；统计推断交praxis-statistics，文本构念交praxis-text-analysis，信息时点交praxis-time-series。当前主要结论需要独立答案时交praxis-verify，不用审计通过代替科学判断。
