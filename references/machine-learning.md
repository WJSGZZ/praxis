# 监督学习：预测对象、分割与基线

用于已明确“用哪些可用信息预测哪个结果”的监督任务。发现相关结构不等于具备预测价值，预测准确不识别干预效应；机制和因果问题分别接已有专业入口。

## 预测契约决定分割

先记录目标人群、一次预测的主体、起点与跨度、输入当时是否可得、输出和实际损失。收益、分类标签与风险概率是不同目标；把相同类别、测量时点或变体混为一个标签会改变问题。目标缺失的处理必须保留覆盖和选择信息，不能默默补目标后再评价。

独立可交换行可以随机分折；同一主体多条记录的跨新主体任务整体留组。GroupKFold保持同组不跨训练/验证，但不证明不同组独立；StratifiedGroupKFold尝试平衡类别，不能保证所有折都有所有类。随机验证不解决未来信息限制，时间问题使用现有时序入口。[sklearn分割文档](https://scikit-learn.org/stable/modules/cross_validation.html)

图片按 [data-analysis.md](data-analysis.md) 的原图源家族先划分，再在训练部分增强；同一原图的旋转、裁剪或近重复不能跨训练与终测。若要推广到新对象、设备、地点或时期，分组应覆盖相应来源，且终测保留部署时实际会遇到的图像质量和类别比例。增强张数不增加独立原图数，按图片随机分割的高accuracy也不证明新事件识别能力。像素处理与测量由 [image-analysis.md](image-analysis.md) 协作，监督目标、标签和最终评价仍由本参考负责。

## 从朴素基线到候选

先在相同分割和人群上用训练均值或训练类别先验；它们能暴露常数目标、类别失衡或复杂模型没有收益。再按目标、数据量、非线性与约束选择简单模型或成熟sklearn估计器，而非按算法名凑模型。对少量样本先比较线性正则化和有解释的特征；需要树/核/其他模型时说明能解决什么现有失效，并保留相同预算和评价口径。

编码、填补、尺度、特征筛选与降维都属于学习过程，只能fit训练部分；类别编码可用ColumnTransformer/OneHotEncoder且规定未知类别处理。Pipeline保护其中已纳入的步骤，不能认证上游特征没有使用目标或未来信息。测试集不得决定模型或变换。[sklearn泄漏与Pipeline](https://scikit-learn.org/stable/common_pitfalls.html)

## 当前可执行工具

`cross_validate_predictor(X, y, task, split, ...)`支持数值特征矩阵、Ridge和0/1 LogisticRegression。`task`为`regression`或`binary_classification`；`split`为`iid`或`group`，后者必须有一组ID/行。group ID为同一种非空string或integer；JSON整数写法1与1.0为同一ID，不将整数1和字符串“1”静默合并。iid收到groups会拒绝，防止丢掉已声明依赖。

本工具不读取原图、不训练CNN或分割网络。由图像取得的数值特征可以按其真实提取链输入；有学习参数的特征提取仍遵守训练折边界，固定外部提取器也须说明版本、训练来源及适用域。完整图像识别需要相应数据、估计器、训练与独立评价，不能由mask测量或数值矩阵CV的成功代替。

参数`ridge_alpha`和`logistic_c`均须正：前者为Ridge alpha，后者为LogisticRegression逆正则化C，仅对应分支使用。参数锁定在整个CV外；工具不执行筛参、最终refit、样本权重或校准。界限为4--5000行、1--100数值列、至多100000格、2--10折；分类优化器500次迭代，未收敛拒绝。界限不等于墙钟、内存或权限隔离。

null特征逐训练折由SimpleImputer中位数填补，然后StandardScaler、估计器都在Pipeline训练内fit。NaN/Inf、boolean数值和缺失目标拒绝；训练折完全缺失列无法学中位数，拒绝而非偷偷丢列。SimpleImputer的策略是一个预测处理选择，不能证明缺失机制可忽略。[SimpleImputer API](https://scikit-learn.org/stable/modules/generated/sklearn.impute.SimpleImputer.html)

输出每折原行索引、组/类别覆盖、训练预处理值、模型和Dummy损失，全部OOF预测及概率/标签。OOF恰覆盖每行一次；训练与验证组相交即拒绝。iid分类要求每类不少于折数；group训练折必须有两类，验证只一类仍可报告定义良好的Brier/accuracy，并显式记录覆盖，不能给它不存在的ROC-AUC。

回归RMSE/MAE是原目标尺度；分类Brier是类1概率误差，accuracy使用0.5阈值且平局归0。总体OOF指标按行汇总，RMSE不是折RMSE的算术平均。折级分数和总体损失各有口径；不同组大小时行权重可能优先大组，需另作与任务匹配的组级评价，工具不会自动替换目标。

## 选择与最终评价

调参、选特征、决策阈值和校准需要训练/内层验证，最终评价保留在外层或另一个未见数据集。同一test多次选择最优会改变它的身份，后续比较按开发结果记录。OOF概率来自不同训练模型，不应把一组混合OOF分数宣称为最终全数据模型的外部校准。

概率评价注明预测对象和目标分布：训练／裁定样本、全部报告、未裁定对象或部署人群不能互换。校准集的来源、标签可得性、类比例与时间范围应支持拟使用的目标；总体accuracy不提供个体概率。选择运输按 [statistical-analysis.md](statistical-analysis.md#概率目标与选择运输) 核对，重采样中未定义指标也按该参考保留；分类排序有用但概率失准时，可交优先级与复核条件，不把分数总和承诺为实际发现数。

按预测用途检查误差：残差和极端样本、目标尺度还原、罕见类precision/recall和代价、概率可靠性、组间差异和新域覆盖。特征重要度反映特定预测器，不等于改变特征的因果效应。区间需要相称的独立单位或专门预测区间方法；普通折间SD/SE不是部署置信保证。

交付保留预测契约、分割、输入版本、参数/软件版本、基线、OOF与所有候选及失败。一个可手算Ridge/常数分类例核计算，一个真实重复主体/验证填补反例核泄漏边界；仍未验证的标签语义、特征可用性、外部校准和应用效果另记。
