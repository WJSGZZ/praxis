# 从实际论文到选手答辩

本参考由 praxis-dialogue 负责教学与训练，praxis-report 提供论文和讲述材料，科学疑问仍交 model／compute／verify。用户要求或目标奖项／阶段明确需要时按需启用，不新建常驻角色，不把答辩设为每篇论文的必经步骤。

## 先确定任务与有效版本

核对赛事、赛项、届次、奖项阶段、官方通知和实际选手。记录讲述／问答时间、语言、人数与分工、材料限制及设备要求；未公布项标待核，练习可用明确标注的临时时长，不能称官方规则。研究生赛2026数模之星需现场答辩，依据为[该届官方邀请函](https://cpipc.acge.org.cn/cw/contestNews/detail/4/2c9080189dcfa24e019dddacc24a1314?page=0)；其他赛事逐项确认，不能从名称或最高奖目标推断必需答辩。

材料绑定当前有效论文版本／哈希、关键计算与贡献来源。沿用案例 planning/tasks.md 的任务 ID、planning/progress.md 的接续和 contributions.jsonl 的真实事件；材料与训练记录放案例 outputs/defense/，不另建任务系统。无真实选手时只能完成材料准备、问题设计或AI自演，真人能力仍待验证。

## 教会、练习、再检验

1. **先诊断理解。** 请选手用自己的话讲问题、核心方法、最重要结果及一个局限。一次一个关键问题；记录真实回答，找出是数学不懂、证据找不到、推理断裂还是表达组织问题，不先给标准答案再称独立掌握。
2. **定向教学。** 从具体数值、输入输出与单位讲到关键公式，再连到为什么选择它、如何检验、何时失效。必要时做手算特例／量级估计；理解解释与独立数学核验分别记录。发现论文自身有错，先回研究与写作修正，不能教选手掩饰。
3. **形成可讲材料。** 按“问题—基线—关键改进—证据—结论与边界”组织故事；选手参与选择重点和分工。关键主张能定位到论文页码／图号及运行证据，复杂推导和补充试验按需备查。沿用现有工具，仅在需要时制作幻灯片并检查实际显示效果。
4. **真实限时讲述与追问。** 选手亲自回答，教练先听完再给反馈。训练可示范和提示；验收阶段先答后评，未回答标未测试。没有音频／视频就只评文字内容，不能推断语速、仪态、现场配合或时间控制已经通过。
5. **补弱后换问题复查。** 指出具体缺口和对应材料，让选手重新推理、计算或改讲法；再用未提前给答案的同类变式或追问检验，保留初答、提示、修订和复查。背会同一道问题只证明该回答熟悉，不证明迁移。

## 追问按作品生成

| 关注点 | 示例方向；须落到本篇证据 |
|---|---|
| 定义与假设 | 为什么这样定义目标？最危险假设失效时结论怎么变？ |
| 数学与数据 | 关键公式的量与单位？参数来自哪里？有没有时间泄漏、不可辨识或近似误差？ |
| 验证与改进 | 比简单基线好在哪里？哪个检查独立？不用这个模块会怎样？ |
| 决策与边界 | 换一种合理偏好／场景仍推荐它吗？哪些问题尚未答完？ |
| 真实工作 | 你本人提出、决定或核验了什么？AI做了哪些工作？失败路线为何放弃？ |

答不出的新问题先澄清条件，说明已有证据能支持到哪里；可现场推导时给出推理，需新增实验时说明验证办法，不编造未做的实验或保证。队员都要理解共同结论与边界；专业细节按真实分工深入，不把一人熟悉视为全队掌握。

## 验收与接续

用实际回答逐项评阅正确性、依据可定位、推理／取舍、边界意识和表达清楚程度。报告“已展示／有提示后完成／仍有缺口／未测试”及具体证据，不设内部总分等同获奖线。关键错误未解决就继续定向训练；约定时间不足时保存缺口与最优先下一步，不无限循环。

训练记录写明选手、论文版本、形式、问题、真实回答／可取得的引用、实际提示、反馈及复查。不能取得完整记录时注明缺失，不能用教练写的示范答案冒充选手回答；教学示意标示意。真实新增研究行动仍按 [contributions.md](contributions.md) 记录，单纯表达熟练不登记为原创研究。

论文或计算改变后，重新核对受影响的讲稿、图、答案和训练结论；旧记录保留其版本，不默认为新稿也通过。交付论文、答辩材料与真人训练状态分别说明。公开或提交仍按原授权，不因准备完成自动发送。
