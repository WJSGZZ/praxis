# 文献来源与论文表达能力

根据实际报告、章节或指定段落选读。已有源文件原位编辑；先冻结有效事实与结果版本，再处理相关表达和产物。外部材料读取前加载 [integrity.md 的材料暴露](integrity.md#材料暴露)，交付时加载其中的 AI 披露与贡献。

## 来源服务于具体论断

搜索前写明待支持的机制、参数、方法或比较，优先第一手论文、官方数据和工具文档。读到实际公式、表格或数值位置，记录标识、版本、条件与页码；摘要、元数据和全文分别标范围。

全文优先从 arXiv、机构作者稿、PubMed Central 或出版社开放版本取得。`search_literature` 返回 OpenAlex 结果与开放链接；`find_open_access` 用 Unpaywall，按 [literature-review.md](literature-review.md) 核真实邮箱授权。arXiv 或宿主已有连接器按实际入口使用。参数记录“值／范围／测量条件／出处位置”。仅取得摘要时写出临时情景身份和依赖检验；关键建议补独立依据或保留条件。付费文献由使用者通过学校等合法渠道取得，实际读到用处后引用。

**参考文献不可省略。** 每个实际使用的外部参数、公式、方法和数据在使用处标编号，文末列作者、年份、题名、出处及可取得的 DOI。引文数量由论断需要决定。`scripts/check_references.py` 用 Crossref 核 DOI、题名与年份；书、标准、网页的 `no_doi` 条目逐项手核。逐条确认原文支持相邻论断，并核责任者、日期和链接。

借鉴 [Manubot](https://github.com/manubot/manubot) 的稳定标识与来源追溯：保留 DOI／原始 URL，再核元数据和论断对应。Praxis 复用这一组织方法，维持现有 LaTeX 工具链；安装与外部服务另按真实任务决定。

## 语言专项：先冻结含义，再分别写作

仅改语言时读取原稿、相关事实与本节。输入为指定段落及任务／结果版本；输出为原位修订、必要对照与未解决歧义。先取得原稿，数值计算只在事实受影响时重做。

1. 冻结数字与单位、变量与公式、比较对象、引用、条件、方向及结论强度；原稿含混之处单独列出，保留研究不确定性。
2. 中文用具体动作与结论代替套话、重复背景和自评，补清指代并拆长定语。分别命名拟合、独立验证和现实解释。
3. 英文围绕读者问题组织：明确主体，采用自然术语搭配，用真实因果／转折衔接；主体无关时可用被动语态，减少机械连接词和过度名词化。
4. 两种语言分别通读，再核同一事实表；信息顺序可不同。条件写在使用处，反复免责声明合并，真实披露按 [integrity.md](integrity.md) 保留。
5. 逐项验事实，再请未见修改标签的读者比较清楚与自然度，保存真实反馈。作者自读标自查，词语检查标机械检查；新手理解另用实际用户验证。

## 论证先于润色

论证、主题链、公式解释和真实取舍按 [scientific-writing.md](scientific-writing.md)，文献综合按 [literature-review.md](literature-review.md)。各章承担明确任务并交代依赖，段落连接主张、依据与推论。题名概括主问题或有据答案，术语全文一致，按推理关系而非算法尝试时间组织。

每项结论回到任务与有效证据：为何选该模型、回答了什么、独立检查支持到哪里、依赖什么前提。分别标推导、实现、实验及现实适用性；最优、因果和泛化范围与原证据一致。这里按数学建模任务吸收 [Mensh 与 Kording](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005619) 的读者与结构建议，具体章节服从本题。

整稿先核“原题要求—前提和模型—结果证据—条件答案”，再顺读标题、段落、图表、引用和结论。缺证据交上游，已有答案埋在无关章节时调整顺序。全文学习分别提炼题意、假设、参数、方法、求解、验证、表达、交付和局限，记录实际来源与适用条件；异题应用及独立检查另外记录。

行动论文把限制目标的机制、模型区分、证据和动作取舍连起来；预测、证明按自身核心问题组织。改变主答案的发现放入对应问题论证，验证节解释可信度。诊断计数、搜索和实现细节按 [convergence.md](convergence.md) 取舍。主线修改后联核摘要、模型、图表、结论与委托方文件；纯组织修订复用仍有效的数值证据。

## 论文骨架、验证与图表

竞赛论文必备件、假设章条件、敏感性五步、验证、Summary 和 Memo 的产出格式唯一按 [contest-paper-checklist.md](contest-paper-checklist.md)；假设合理性与证据条件按 [methods.md](methods.md#假设理由与结论范围)。下面处理表达与编辑选择。

- **前部与章节**：核当届规则，再按论证安排背景、问题、文献、符号和数据来源。标题命名具体对象、方法、结果或验证任务，同层语法与粒度一致。一个标题覆盖该节主要内容；涉及界或最优性时写明策略／模型范围。编号子节用于并列内容，一个 x.1 优先并入父节；确有独立导航或规定结构理由时保存源码绑定的审阅说明。先独立读目录，再核真实换行、引线、页码、交叉引用和正文对应页。
- **模型与公式**：解释关键定义、依据、求解保证、参数和结果；复杂算法可给伪代码，短解析题直接推导。完整讨论用连贯段落，假设、步骤、分情形及互斥决策可编号；列表保持职责平行。公式后解释符号、单位及它改变了哪项判断。
- **参数**：给来源、算式、单位与测量条件。无直接数据时可按已知定律对有据参照物缩放，或拟合已发表数据；把缩放与拟合身份写清。声明参数交敏感性检查其影响。
- **范围与逆问题**：报告多种工作点、收益小或失效的情景，解释容量拐点。反问题先查唯一性，列出相容解，用独立观测区分；核已使用全部相关信息及误差敏感方向。经验多项式注明拟合区间，物理解释另找机制依据，位数与数据精度相称。
- **独立检查的写法**：拟合误差描述样本贴合程度，重复同一实现描述一致性。写清解析、仿真、留出或实测比较分别支持什么；同一工况并列原始输出，不一致处追原因。检查数量与状态从 [automation.md](automation.md#写作连接) 的真实证据读取。
- **图**：先比较文字、表格和图的阅读价值，选型、工具与数据忠实度按 [visualization.md](visualization.md)。每张图回答一个读者问题，先在正文引用再放图。简单解析结果可以不画图；复杂数值场可沿用成熟科学绘图库，工具随核查任务选用。
- **图题与说明**：当前美赛 `\caption` 只放短名称，最多15个英文词／30个汉字；条件、方法、面板对应、样本／版本、区间与失败标记放首次引用附近、figure环境之外的普通正文，核清居中段落／minipage的职责。图内轴、单位、色标和图例已说明的内容保持简洁。图例命名实际系列。采用独立 figure legend 的期刊按其规范组织标题与说明。该短图题是项目选择，官方要求另核。
- **图题联核**：改一张后核全稿图题、邻近解释、正文引用、生成源、当前 PDF 和公开副本。当前编译／冻结检查多句长图题及 figure 内尾部说明；`review_figure_titles` 提供字面定位，`--review-captions` 仅作传统长度提示。实际页面继续核语义、最终字号、居中、遮挡、版心和换行；历史稿用 archive 保留原件。
- **证明**：用 `amsthm` 的 `proof` 环境界定证明，末尾默认空心方框；显示公式结束时按页面使用 `\qedhere`。应用和数值解释另起段，图例中的方形数据符号按图例角色处理。
- **委托方文件**：按 checklist 组织非技术文件，再逐项对技术正文核数字、单位、对象／模块、时点、动作、关键条件和预算包含关系。分别命名保险费、补贴、资本、工程费等角色，明确有限期支持期限；场景与图例保留真实来源或自绘说明身份。

图题分工的既有核读记录（2026-10-13）：[PLOS One](https://journals.plos.org/plosone/s/figures) 区分短 figure title 与可选 legend，[Nature npj](https://www.nature.com/documents/npj-gta.pdf) 区分标题、面板／符号和误差说明；组织方式另参考 [Wilke](https://clauswilke.com/dataviz/figure-titles-captions.html)。竞赛短图题把必要说明放邻近正文，按用途采用对应政策。

## 去掉防御性的话，并让每张图表都被正文引用

写完后只改文字做一遍删繁：真实条件和数据缺口在使用处各写一次，把关键结果与依据留在阅读主线。每张图表都有正文引用及其支持的论断；`scripts/contest_rules.py` 列出只在自身图题出现的图表供复查。每篇论文的图表计划、默认结构图与空间地图、数量告警和省略理由唯一按 [visualization.md 的图表计划](visualization.md#图表计划)。

## 中文论文与英文论文各按自己的习惯写

同一成果中英文核同一份事实、数字与条件，各自组织和通读，再对照事实表。

**中文（国赛等）**：摘要按实际问题展开，动词具体（建立、求解、检验、证明）；句子短，公式后用“其中”解释符号与单位。首次出现定义术语、缩写，数字配单位，小数位与精度相称；中文用全角标点，数字与公式用半角。用具体检验与数值说明稳健性。

**英文（美赛等）**：Summary 按 checklist；正文每段一个论点，以主题句引导，选清楚的主体和自然搭配。方法与定义常用现在时，已做实验与结果用过去时；写 “Section 3”“Table 2”，缩写首次定义，数值与单位间留空格。用具体动作和结果替代 “Aiming at…”“has strong robustness”；用 “within 3% of…” 等精确范围表达不确定性。

各配一个只读该语言成稿的评审，按 [review-protocol.md](review-protocol.md) 核自然度、术语与数字。

## 接收与交付

接收任务 ID、允许主张、有效数值与单位、图表、来源和未决事项，先写有依据部分，将关键缺口交相应能力。整稿修订先读全文，完成后复核摘要、假设、符号、结果、结论和附录的协调；语言任务沿冻结事实操作，计算只重做受影响部分。

结构预检、模板、身份、赛事编译与冻结按 [contest-delivery.md](contest-delivery.md) 导航，完整执行 API 见 [automation.md](automation.md#写作连接)。静态树候选与实际目录逐项对照，保存确有独立职责的层级理由，实际 PDF 和科研论证分别审阅。研究稿按 [research-mode.md](research-mode.md)，确定期刊后核其投稿要求。

问题回到来源修：事实／规则核原来源，变量／假设回模型，数值回运行与验证，图形回生成脚本与共享配置，版式与引文回写作。图题过长时重新分配短标题、邻近读图说明和结果分析；保留单位、阈值、样本与条件。引文逐条阅读核论断支持，成稿再搜占位符及跨章数字冲突。来源、AI 披露和材料接触按 [integrity.md](integrity.md)，原始交互按 [feedback.md](feedback.md)。

交付 PDF 前逐页渲染，核图、表、代码框的版心、居中与字体，方法见 visualization 的“版心边界”。PDF 中文检查用共用 `scripts.pdf_text`；Adobe-GB1 等标准 CID 字体缺 ToUnicode 时用 PDFium 内置映射，字符提取、字体嵌入和视觉分别验证，再查匿名、摘要与计页。公开展示沿项目视觉规范，比赛论文按科研与赛事规范选择。
