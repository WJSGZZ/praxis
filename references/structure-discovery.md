# 结构发现：问题背后是什么数学对象

题目不熟、没有现成模型可套、或想知道有没有更好的路线时读。目的是在选模型之前先问：这个问题的**结构**是什么，结构带来什么推论，怎样低成本地验证这个判断。已有标准做法的熟悉题，一两分钟扫一遍问题清单即可，不必写成文档。

结构是假设，要被攻击：数值探测找不到反例只是证据，找到反例才是证明（见各工具的 `proved` 字段）。

## 先问什么

| 问题 | 为什么问 | 怎样探测 | 找到后的推论 |
|---|---|---|---|
| 哪些量是状态，哪些是决策，哪些是常数？ | 决定问题是静态优化、动力学还是控制 | 逐个量写出“由谁决定、随什么变” | 状态加决策是控制问题；只有决策是优化；只有状态是动力系统 |
| 有没有守恒或平衡关系？ | 守恒关系可降维、给界、检查单位 | 写出“流入减流出等于积累”；`probe_structure`（invariant）检验候选守恒量 | 消去变量；能量或质量平衡给下界；对称的流入流出可当检验 |
| 有没有对称性？ | 对称可以合并变量、预言等分或相等解 | `probe_structure`（symmetry）；手工交换两个对象看目标是否不变 | 对称且凸时最优解可取对称点；对称破缺要有来由 |
| 目标对某个变量是否单调？ | 单调就把连续决策变成阈值或边界决策 | `probe_structure`（monotone）；解析求导 | 递增则取边界；“先等再保持”“能延后就延后”类策略 |
| 凸还是非凸？ | 凸问题的局部解就是全局解，非凸要多起点或松弛 | `probe_structure`（convexity）；解析 Hessian | 凸：用凸求解器并以对偶间隙作证书；非凸：报告局部，找松弛界 |
| 有没有量纲齐次或标度关系？ | 无量纲化减少参数个数，暴露主导机制 | `dimensional_analysis`（Buckingham Pi）；`probe_structure`（power_law） | k 个变量、r 个基本量得 k−r 个无量纲组；幂律意味着标度不变 |
| 约束矩阵有没有图或区间结构？ | 网络矩阵保证 LP 顶点是整数 | `check_total_unimodularity` | 全单模：LP 松弛即整数最优，不必上 MILP |
| 能否分阶段、有无递推关系？ | 递推结构可用动态规划，把指数搜索变成线性 | 把问题写成“阶段、状态、转移、收益”四项 | 状态数可控则 DP 给全局最优 |
| 随机性从哪里来？ | 区分参数未知、观测噪声、机制随机 | 写出数据生成过程；做先验预测检查 | 决定用概率模型、仿真还是情景范围 |
| 时间或空间尺度是否相差很大？ | 快慢分离可近似，也可能出刚性 | 估计各过程的特征时间；`scaling_exponents` | 快变量准稳态；慢变量用平均；刚性问题换积分器 |
| 能否变成另一个已知问题？ | 同构问题的现成结论可整体借用 | 放松、对偶、变量替换、取对数、线性化后再看 | 松弛给界，对偶给证书，变换后可能是 LP、流或匹配 |

## 从现实机制到数学结构

不要建一个“所有学科知识库”。要学会的是：**现实里的什么机制，对应数学里的什么结构**。步骤是：领域机制 → 数学结构 → 方法族 → 该方法族的必做检查。机制的描述要有权威出处（教材、标准、已发表的测量），没有出处的写成假设。

| 现实机制 | 数学结构 | 方法族 | 要核对的 |
|---|---|---|---|
| 资源有限、要分配 | 线性或整数规划；网络流；指派 | `solve_lp`、`solve_milp`、`max_flow`、`solve_assignment` | 约束量纲；对偶或界；整数性（可用全单模判断） |
| 某量随时间积累或衰减 | 一阶常微分方程；线性系统；矩阵指数 | `scipy.integrate`、矩阵指数 | 守恒量；解析极限；步长收敛 |
| 个体状态转移（健康、故障、客户） | 马尔可夫链；舱室模型 | `sir_simulate`、线性方程组求稳态 | 转移概率来源；稳态是否荒谬 |
| 传染、扩散、传播 | 网络上的常微分方程；反应扩散方程 | `sir_fit`（带可辨识性）、有限体积 | 基本再生数阈值；参数可辨识性 |
| 热、质量在空间中输运 | 偏微分方程；热网络 | 有限体积或差分、矩阵指数 | 守恒；网格收敛；边界条件的物理来源 |
| 排队、等待、容量 | 排队论；离散事件仿真 | `queue_mmc`、仿真 | 利用率小于一；Little 公式；到达是否泊松 |
| 决策人之间互相影响 | 博弈；线性规划求混合策略 | `solve_lp` | 支付来源；是否真是零和 |
| 分阶段、随状态变化的决策 | 动态规划；马尔可夫决策 | 反向递推 | 状态空间大小；折现与终端条件 |
| 观测有误差、要推断隐藏量 | 统计模型；状态空间；卡尔曼 | statsmodels、PyMC | 残差、识别性、预测检验 |
| 多方案比较、有多个指标 | 多目标；评价；支配关系 | `evaluate_alternatives`、前沿 | 先查支配；权重来源；排名翻转 |
| 事件的先后、依赖、网络 | 图；最短路；最小生成树；连通性 | `shortest_path`、`minimum_spanning_tree` | 权重含义；有向无向 |
| 对不确定参数下的稳健决策 | 情景分析；鲁棒优化；全局敏感性 | `sobol_sensitivity`、情景表 | 范围依据；独立性假设 |

## 记录与检验

- 发现的每个结构登记在路线记录里（`route_graph` 的 `add_structure`），写明依据等级：已推导、有引用、已检验、仅假设、未知。
- 结构的推论只在结构成立时才可用。把“凸”当成事实去用凸求解器，而结构只是“没找到反例”，要在结论里降一级。
- 用小例子检验结构判断：取一个能手算或穷举的小规模版本，看依靠该结构得到的结论是否与暴力结果一致。
- 发现原先的结构判断错了，回到路线选择，不在下游悄悄改假设。

## 三个已验证的例子

1. **浴缸保温**：能量平衡给出线性常微分方程；热损失随温度单调增加，推出“先滑行到下限再保持”最优；能量守恒给出对任意控制的下界。见美赛案例。
2. **含最低费用的组合**：费用是分段函数，用二元变量写成混合整数线性规划；去掉最低费用得到比例费用的线性松弛，它给出解析上界；资金够大时两者等价。见国赛案例。
3. **调运网络**：约束矩阵是有向图关联矩阵，`check_total_unimodularity` 判定为全单模，所以不必用整数规划，线性规划的顶点解就是整数。
