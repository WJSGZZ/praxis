# 定义歧义的区分例子

仅在 references/methods.md 的“明确问题”环节发现真实歧义时读此参考；正常题目不另走一套审查流程。定义、取舍与影响记录到对应任务 ID 的 planning/tasks.md。以下例子用于区分解释，不是固定必查清单。

- “平均增长”：平均各期增长率，与首尾的复合增长率是两种量。用先增长 100% 再下降 50% 的例子区分：算术平均为 25%，复合增长为 0%。根据题意确定分母与时间跨度。
- “所有点都有设备覆盖”：每点可由不同设备负责；“存在一个设备覆盖所有点”更强。不要因对称例子给出相同答案就混为一谈。
- “面积覆盖率”：两区域有重叠时，覆盖面积使用并集；除非任务定义的是重复服务次数，否则不能简单相加。
- “最优”：说明是已检查候选中最好、离散网格中最好、局部解还是全局最优。有限采样不能直接支持连续空间的全局断言。
- 预测：每个开发和最终测试样本的目标时间必须分开；特征与处理参数只能使用当时可获得的信息。


独立证据、跨任务依赖与失败返回规则统一见 references/methods.md；这里不维护第二套规则。
