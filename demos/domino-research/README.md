## 问题与难点

用 1×2 的骨牌铺满 3×2n 的矩形，有多少种铺法？记这个数量为 a(n)。小棋盘可以直接数，大棋盘则需要找出规律，并证明它一直成立。

这是经典组合计数问题。本案例重建其推导，展示计算、猜测和证明之间的连接；核心难点是**“检查了很多项”为什么仍不等于“对所有 n 成立”**。

## 主要结果

| 结论 | 依据 |
|---|---|
| **a(n)=4a(n−1)−a(n−2)**，a(0)=1、a(1)=3 | 棋盘分解与转移矩阵给出两种独立证明。 |
| 通项为 ((3+√3)/6)(2+√3)ⁿ + ((3−√3)/6)(2−√3)ⁿ | 由递推求解；相邻项比值趋于 2+√3。 |
| a(0)…a(16) 为 1, 3, 11, 41, 153, …, **1117014753** | 三种方法互证到 n=5，转移矩阵与递推核对到 n=16。 |
| 不存在次数 ≤8 的多项式计数公式 | 指数增长排除多项式形式。 |

## 推导与验证

先用回溯枚举、八状态转移矩阵和局部分解的耦合递推计算小棋盘，比较三种结果。随后只用前 13 项寻找递推，保留 a(13)…a(16) 作检验，并搜索 2≤n≤60 的反例。

全尺寸结论来自两种证明：

- **构造分解。** 穷尽最左侧骨牌的摆法，得到两个耦合递推，再消去辅助计数。
- **有限状态证明。** 八状态矩阵给出“递推阶数不超过 8”的数学依据。候选递推的差序列也满足该阶数界，核对其前八项为零，即可推出恒为零。

关键在于阶数上界来自矩阵结构，不能由拟合效果代替。反例搜索和留出检验用于攻击猜测，所有尺寸的证明另有明确前提。路线与淘汰记录见 [reproduce/reference/](reproduce/reference/)。

## 作品评议

**这是一份正确、清楚的经典结果讲解，适合作为计算发现与证明复核的示范。**

优点是两种论证互补：棋盘分解解释递推的来源，转移矩阵解释有限检查为何足够；计数、猜测和全尺寸证明的证据等级区分清楚。

作为原创研究，中心递推已知，尚无新的定理或研究后果。因此，现有贡献主要是教学与方法展示，不能仅凭增加计算或改善版式认定为顶尖期刊研究。

## 计算复现

在 Praxis 仓库根目录执行：

```bash
uv sync --locked
uv run --locked python demos/domino-research/reproduce/explore.py
```

入口重算计数与各项检验，结果写入 `reproduce/reproduced/`，不改归档结果；再次执行会更新该复现目录。数值复现无需排版工具或 AI 服务。

可选重新排版：`uv run --locked python demos/domino-research/reproduce/build_note.py`，需要 Tectonic 0.17.0 及固定资源包。
