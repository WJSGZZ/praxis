# 研究模式案例：3×2n 多米诺铺法数

**没有标准答案时怎样工作：猜规律、留出检验、找反例、用两种方法各证明一次，并给每条结论标明把握。**

[English](README.en.md) · [研究笔记（PDF，英文）](deliverables/paper.pdf) · [复现代码](reproduce/) · [返回 Praxis](../../README.md) · [案例总览](../README.md)

## 这道题问什么

用 1×2 的多米诺骨牌铺满 3×2n 的矩形，有多少种铺法？记为 a(n)。题目只给了问题本身：没有标准答案，也没有可套的模型，要自己找出规律并证明它。这是一个经典结果，案例不声称新发现；它用来演示 Praxis 的研究模式怎样把“看起来对”变成“证明了”。

## 先看结果

| 结论 | 把握 | 依据 |
|---|---|---|
| a(n) = 4a(n−1) − a(n−2)，a(0)=1，a(1)=3 | **已证明（两种独立证明）** | 按最左列分类的构造证明；转移矩阵阶数上界加 8 条方程的有限核对 |
| 通项 ((3+√3)/6)(2+√3)ⁿ + ((3−√3)/6)(2−√3)ⁿ，比值趋于 2+√3 | 已证明 | 由递推推出 |
| 前 17 项 1, 3, 11, 41, 153, … , 1117014753 | 已检验到 n=16 | 三种算法共同核对到 n=5；转移矩阵与递推核对到 n=16（摘要范围从归档数组生成） |
| 不存在次数 ≤ 8 的多项式公式 | 已证明 | 增长是指数的 |

## 怎样做

1. **三种独立算法算小例子**：回溯枚举、转移矩阵（8 个列状态）、由局部分解得到的耦合递推，互相核对。
2. **猜规律**：对前 13 项做精确有理数搜索，得到阶数为 2、系数 (4, −1) 的递推：11 条方程、2 个未知数；同时否定多项式公式。
3. **留出检验与找反例**：猜测时不用 a(13)…a(16)，它们全部满足；对 2≤n≤60 穷举，没有反例。
4. **证明两次**：按最左列分类得到 A、B 两个耦合递推并消元；独立地，用转移矩阵的阶数上界 N=8，证明候选递推的差序列也满足同一个 8 阶递推，前 8 条方程成立即恒成立。
5. **记录**：用 `route_graph` 保存三条路线（猜递推、猜多项式、按列分解）及淘汰原因，用 `route_to_lesson` 起草一条可迁移的经验。

## 证据与验证

- 三种算法在能互相比较的范围内完全一致；
- 递推在留出的 4 项和 n≤60 上成立，并被两种独立的证明各自证明；
- 有限核对的结论依赖“阶数不超过 8”这一前提，它来自 8×8 转移矩阵（Cayley–Hamilton），不是靠数据猜出来的；
- 每个结论按把握阶梯标注：已检验到 N、已证明（有限核对）、已证明；独立计数与有限核对不等于证明助手形式化认证。

## 研究评价

当前4页稿的作者外AI全文审读：**正确、清楚的经典结果讲解，适合作为证明与复核流程示范；目前不属于顶尖数学期刊的原创研究。**不能把已知结论的正确性和漂亮版式换算成原创性。

| 方面 | 当前判断 |
|---|---|
| 正确性 | 两种证明、通项与生成函数得到支持；有限到无限的关键是已证明的阶数上界。 |
| 新颖性 | 中心计数和递推已见经典文献，不能视为新结果。 |
| 重要性 | 有教学价值；尚无新的研究定理或重大后果。 |
| 方法 | 有限状态与证明阶数界的连接可复用，不是仅凭有限数据猜测。 |
| 表达 | 检验、证明和经典结果身份交代清楚。 |
| 可核查性 | 独立小棋盘计数与八条差分方程一致；不是形式化认证。 |
