## 问题与难点

本例使用快捷 Collatz 映射：偶数除二，奇数乘三加一后除二。研究的问题是：迭代何时第一次低于起点？它的步数与奇数步不除二的原映射不同。

把一段迭代写成“系数 × 起点 + 偏移”。系数首次小于 1，实际数值却未必下降，因为正偏移可能抵消收缩。记首次系数收缩为 τ、首次实际下降为 σ，研究利用“此前从未收缩”的约束，寻找二者相等的条件。

## 主要结果

| 结论 | 证据与范围 |
|---|---|
| **对任意 n>1，若 τ(n)≤1024，则 σ(n)=τ(n)** | 锐偏移包络、有限归约证明与精确检查；n 没有大小上限，较大或无穷的 τ 不在结论中。 |
| 潜在例外只需检查起点 **2…72058** | 647 个可行首次收缩深度给出最坏界；72057 个起点已全检，无失败或达到步数上限的未决项。 |
| 未覆盖自然密度约 **1.1537401×10⁻¹⁹** | 压缩状态计数与独立二项递推一致；该量不是发散概率，也不能视为零。 |
| 归一化最大偏移趋于 **1/(6 ln 2)** | 精确恒等式与均匀分布论证给出极限；没有声明有限深度的误差率。 |
| 固定深度和固定包络扫描界无法覆盖一般情形 | 构造未覆盖起点并证明充分扫描界无界增长；这既不是猜想的反例，也不排除其他路线。 |

## 证明与计算

1. **建立首次收缩屏障。** 所有此前的奇偶前缀都必须保持不收缩，形成整数约束。
2. **求锐偏移包络。** 约束决定奇数步最晚可以出现的位置；一个序列同时达到这些界，给出最大偏移。
3. **归约潜在例外。** 若收缩时尚未实际下降，起点必须不超过“偏移 ÷ 收缩量”。在可行深度中取最大值，得到 72058。
4. **分离生成与检查。** 生成端使用屏障序列和前向计数；检查端使用 max-plus 状态极值、二项首次到达递推及直接整数轨迹。
5. **刻画路线局限。** 包络极限与无界扫描条件说明，单纯增加计算深度仍留下哪些结构问题。

六类损坏证书测试分别改动偏移、阈值、收缩深度覆盖、密度、扫描范围与直方图，检查器均予拒绝。[核验摘要](verification.json)绑定源码、PDF 和实际计算记录。

## 作品评议

**这是一份有实质推导与精确核验的综合计算笔记，原创研究贡献尚未建立。**

主要优点是将无限整数域上的条件命题归约为可检查证书，并用不同递推核对极值和计数。论文也解释了当前路线的局限，区分条件定理、自然密度与完整猜想。

新颖性是主要缺口：所引 Rozier–Terracol 定理 5.3 与推论 5.4 已陈述更强覆盖，深度 1024 因此不能作为新的研究纪录。包络与归约的独立价值仍需逐定理定位，现有材料不足以认定重大原创进展。

## 计算复现

在仓库根目录执行，先建立新副本，避免改动归档：

```bash
uv sync --locked
uv run --locked python -c "from shutil import copytree; copytree('demos/collatz-research/reproduce', '.session/collatz-replay')"
uv run --locked python .session/collatz-replay/code/verify.py
uv run --locked python .session/collatz-replay/code/analyze.py
```

`copytree` 拒绝已有目标。核心脚本只用 Python 标准库：`verify.py` 核验证书，`analyze.py` 生成展示小数；如需重建证书，再执行副本中的 `code/certify.py`。计算时间不代表文献阅读、推导和审稿投入。
