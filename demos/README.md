## 决策分析

### 收费之后，瓶颈在哪里？

**2017 MCM B · Merge After Toll · 17 页英文报告**

更多收费窗口不一定带来更短等待。研究把支付兼容、汇合几何与有限排队空间连接起来，保留首稿、反例、被拒绝的路线和独立核验。这是往年竞赛题上的条件性决策研究，作为固定研究归档展示。
