# 展示图与视觉规范

Praxis 的宣传图共用一套视觉规范，用版式区分两类信息：左边暖白纸面讲问题，放标题和图；右边深群青色块给证据，放米白色的大号衬线数字。`visual-style.json` 是唯一配置，里面有画布、颜色、字体字面、文字角色、网格和线宽；`showcase.py` 是唯一模板，负责纸面、色块、标题区、证据栏、页脚、坐标轴和图例。各案例脚本只写内容，并为每段文字选角色，不写字号、颜色或坐标。

## 规范

**构图与留白。** 画布 1920 × 1080，色块从 x = 1248 开始，一直延伸到画布右边缘。
- **边距：** 纸面四周 112 px，色块内 96 px，上下相同。
- **对齐：** 纸面的栏目标记和色块的 PRAXIS 在同一条基线上，纸面最后一行条件句和色块最后一行注释也在同一条基线上。
- **证据数字：** 在色块里上下等距排列，彼此间距和到上下边的距离一样。

所有文字按基线排，坐标都写在配置的 `layout` 里。

**字重表达层级。** 不全用细体，层级由字重表达。

| 用途 | 中文 | 拉丁字母与数字 |
|---|---|---|
| 标题 | 粗宋体 STSongti-SC-Bold | 半粗 Baskerville-SemiBold |
| 证据数字、页脚结论 | 宋体 | Baskerville 常规体 |
| 栏目标记、图注 | 冬青黑体 W6 | Helvetica Neue Medium |
| 副题、刻度、说明 | 冬青黑体 W3 | Helvetica Neue |

字体按实际字符选择。

**字号（px）。**

| 角色 | 字号 |
|---|---|
| 标题 | 中文 76；英文 68（拉丁字面更宽，英文标题另写短句） |
| 证据数字 | 100；一张图有三到四个数字时用 66 |
| 副题 | 28 |
| 结论 | 28 |
| 图注、标签 | 22 |
| 刻度、图例、条件 | 19–20 |

最小 19 px。放不下就缩短文案，不缩字号。生成器会检查纸面文字是否越过色块、色块文字是否超出右边距。

**颜色。**

| 位置 | 颜色 |
|---|---|
| 纸面 | 底色 `#F6F5F0`，墨色 `#2B2730`，次级灰 `#646B70`，细线 `#D6D4CC` |
| 图中主角 | 群青 `#263B9B` |
| 真实对比或留出检验 | 朱红 `#C8533B`；色块上用浅朱红 `#F2957A` |
| 色块 | 底 `#1F2A66`，主数字米白 `#F5F0E4`，标签与参照值 `#AAB3D8` |

**线与图表。**
- 主曲线 3.0，次曲线 2.0，引导线 1.2，细线 1.0，标记 9。
- 只留底轴和横向细网格，不画边框。
- 纵轴量写在图左上的图注里，不竖排；横轴名写在图下方。
- 图例与图注同行，右对齐到纸面边缘。

**内容。**
- 一张图只讲一个中心问题，证据数字至多四个。
- 页脚结论里的推导数字必须与证据栏显示的数字一致。
- 中英文分别写标题和说明；数字、范围和条件必须相同。

Logo 只用于项目首页，不叠加在宣传图上，也不进入论文。

## 生成

在仓库根目录运行：

```sh
uv run --locked python demos/assets_src/make_overviews.py
uv run --locked python demos/assets_src/make_research_overviews.py
```

第一条生成国赛、美赛两张主图和国赛结果图，第二条生成两个数学研究案例的封面，都输出中英文两版。数值取自案例的归档结果和当前 PDF 的页数，改展示文案不需要重算模型。

字体按配置里的 PostScript 名称，从本机字体集合中取出确切字面，存到 `.session` 临时目录，用完删除。不合成字重，不静默替换，也不打包字体文件。其他平台可以用 `PRAXIS_FONT_CHINESE_SERIF`、`PRAXIS_FONT_CHINESE_SANS`、`PRAXIS_FONT_LATIN_SERIF`、`PRAXIS_FONT_LATIN_SANS` 指向有权使用的本地字体文件，然后重新做视觉验收。这条依赖不影响论文的跨系统 Fandol／newtx 排版链。

## 验收

生成器会检查缺字、文字出界、文字相交，以及证据栏是否超宽，检查失败就不保存新图。`tests/test_showcase.py` 比较每组中英文成品里应当完全相同的区域，包括页眉和证据数字区，按像素比对。

自动检查不能证明线条、标记或数学含义正确。每次改版还要实际查看三种尺寸：1920 px 原图、约 900 px 的首页宽度和 390 px 的手机宽度。手机缩略图只负责识别和点击入口，关键条件同时写在 README 和案例正文里。

## 科学图不用品牌样式

技能演示里的科学图展示的是 Praxis 交给论文的实际产物，所以不用品牌配色和 Logo，统一使用论文的图形样式。这些图包括数据分析、图像分析和空间分析三个演示：

- 前两张用 pgfplots，配 newtx 的 Times 字体；
- 空间分析用 Matplotlib 加 `templates/praxis.mplstyle`，生成时传 `--praxis-style`，同样是 Times 字体、12 pt。

论文与演示里的科学图表按期刊规范制作：配色用 Okabe–Ito 色盲友好色板（`scripts/texplot.py`、`templates/praxis.mplstyle`），蓝色 `#0072B2` 表示关心的量，朱红 `#D55E00` 表示对比，灰色表示背景和界，颜色另配线型，灰度打印仍能区分。品牌规范不改动这些图，论文截图保持原样。
