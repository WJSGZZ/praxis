# 展示图

`visual-style.json` 是画布、品牌色与字体角色的唯一配置；竞赛与研究使用各自的适用配置。修改配置或文案后，从生成源重建，不手改导出的图片。论文中的科学图表仍按 `references/visualization.md` 与论文模板验收。

已采用的[品牌Logo](praxis-logo.png)以开放曲线与未连接的留白表达探索未知、承认未解边界。群青为主强调色、朱红用于对比；Logo与主题色的使用边界由源码仓库的 `CONTRIBUTING.md` 规定，不进入科研或竞赛报告。现有宣传图通过共享配色使用这一视觉主题，论文截图保持原样。

在仓库根目录运行：

```sh
uv run --locked python demos/assets_src/make_overviews.py
uv run --locked python demos/assets_src/make_research_overviews.py
```

两条命令分别生成国赛／美赛旗舰和数学研究的中英文展示图，数值读取案例的归档结果与当前PDF页数。改变展示文案不重算模型。中文和英文各自组织标题与说明，再核对数字、条件及含义。

研究图以一个数学问题为中心，采用一张图、至多两个醒目的证据数字，页数放在页眉。整组宣传图共用 `showcase.py` 的字体与验收：汉字标题用宋体，中文正文用冬青黑体 W3；拉丁标题用Baskerville，正文中的英文、阿拉伯数字和单位用Helvetica Neue。字形按实际字符选择，中文图中的英文与数字也遵循相同角色；数学轴刻度使用Matplotlib数学排版，两种语言保持一致。按配置中的真实PostScript名称选择本机字面，不合成字重、不静默替换、不打包字体文件。再生成依赖这些获准使用的本机字体；其他平台可用 `PRAXIS_FONT_CHINESE_SERIF`、`PRAXIS_FONT_CHINESE_SANS`、`PRAXIS_FONT_LATIN_SERIF`、`PRAXIS_FONT_LATIN_SANS` 指向本地文件，并在配置中明确真实名称后重新视觉验收，现成PNG可直接查看。该依赖不影响论文的跨系统Fandol／newtx排版链。

生成器检查缺字、文字出界、文字相交和研究右栏超宽，失败时不保存该张新图。`tests/test_showcase.py` 直接比较五组双语成品的固定英文页眉与关键数字区域像素，防止仅更换语言就改变字面或位置。自动检查不证明线条、标记或数学含义正确。每次改版还需查看1920px原图、约900px桌面宽度与390px手机缩略效果：手机图承担识别和点击入口，小字不作全部可读的承诺，关键条件同时保留在README与案例正文中。

国赛封面的留白与左右信息层级沿用已审阅的HTML/SVG样板，正式PNG仍由现有Matplotlib生成器从归档CSV生成；没有新增浏览器渲染依赖。共享字体层修正其余竞赛与研究宣传图，保留各自的图表职责。Logo只位于项目首页，未叠加进报告页预览。

离散核验深度的数据以点表示；引导虚线说明用途，不暗示连续插值或额外已证实深度。保留会改变结论的条件，不以大数字或专业版式提升证据等级。两个研究案例分别写文案，同时检查字体角色、边距、字号和图表职责的协调性。
