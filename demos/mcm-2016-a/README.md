# 美赛 Demo：一缸水，怎样保持温暖又少补水？

**2016 MCM A《A Hot Bath》——从平均水温，走到空间差异、策略比较与可检查的结论。**

[English](README.en.md) · [完整英文论文](deliverables/7391856.pdf) · [复现源码](reproduce/) · [返回 Praxis](../../README.md)

[![美赛案例：空间水温与三种补水量证据](assets/overview-zh.png)](deliverables/7391856.pdf)

把整缸水当作已经充分混合，最佳办法是先等水温下降，再补水维持下限；但加入空间输运后，基准情景中较早开始小流量补水更好。这个案例用一个可以证明的简单模型，检验一个更接近问题结构的三维模型，而不是堆更多算法。

| 同一 30 分钟情景 | 补水量 | 能支持什么结论 |
|---|---:|---|
| 三维热网络选中的策略 | **10.48 L** | 已接受候选中用水最少；不声称任意控制的全局最优 |
| 理想充分混合模型 | **6.53 L** | 在该理想模型中证明“先等再维持”最优 |
| 能量守恒给出的下界 | **5.98 L** | 给定温度与热损假设下，任意可行策略的条件下界 |

水量 164.25 L，初始 40°C，下限 39°C、上限 40.5°C，允许最大空间温差 1.5°C。热损、混合和人体参数都是公开的假设情景；没有实测浴缸实验。这些数值用于展示方法，不是普适的使用或安全标准。

## 看点在证据，而不只是曲线

- **空间差异会改变策略。** 三维有限体积热网络显式处理表面和壁面散热、人体置换及换热、内部混合、入流与溢流。每个单元都接受约束，平均值不能掩盖冷区。
- **三个结论等级分别表达。** 理想模型有最优性证明；空间模型有可行候选；能量守恒有条件下界。三者之间的差距保留下来。
- **验证不只重复运行。** 独立热流 RHS 的 RK45 对照矩阵指数，另核对能量、解析极限、几何算术和情景回放。17 项检查并不等于 17 套算法。
- **检查采样点之间。** 基准策略使用导数包络核对全时间温度约束，并注明前提、浮点误差余量和适用模型。情景检查仍是采样验证，不借此扩大结论。
- **保留失败与分辨率差异。** 弱混合等情景没有接受候选；细网格水量约 10.47 L，但局部温差增大。没有把两套网格说成充分收敛证明。

## 复现计算

在 Praxis 仓库根目录运行：

```bash
uv sync --locked
uv run --locked python demos/mcm-2016-a/reproduce/run_demo.py
```

脚本重算基准、16 个变化情景和细网格，执行 17 项模型检查，再增加 1 项与论文归档水量的比较。约需一分钟，实际时间随设备而变。输出写入 `reproduce/reproduced/`，存在时拒绝覆盖；它不会修改归档证据或最终 PDF。这里的 18 项复现检查不能回写成论文中 17 项模型检查。
