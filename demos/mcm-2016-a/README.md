# 美赛 Demo：一缸水，怎样保持温暖又少补水？

**2016 MCM A《A Hot Bath》——从平均水温，走到空间差异、策略比较与可检查的结论。**

[English](README.en.md) · [完整英文论文](deliverables/7391856.pdf) · [复现源码](reproduce/) · [返回 Praxis](../../README.md)

[![美赛案例：空间水温与三种补水量证据](assets/overview-zh.png)](deliverables/7391856.pdf)

把整缸水当作已经充分混合，最佳办法是先等水温下降，再补水维持下限；加入空间输运后，恒定流量应当一开始就补，而随时间变化的方案还能再省约 18%。案例用一个可以证明的简单模型检验更接近问题结构的三维模型，热损与人体换热系数取自标准关联式和已发表的浸浴实验，并给出范围。

| 同一 30 分钟情景 | 补水量 | 能支持什么结论 |
|---|---:|---|
| 三维热网络，最佳恒定流量 | **24.14 L** | 已接受候选中用水最少的恒定流量；不声称任意控制的全局最优 |
| 三维热网络，12 段分段恒定流量 | **19.77 L** | 约束优化得到的局部最优；开头 2.5 分钟与最后 10 分钟不补水 |
| 理想充分混合模型 | **16.01 L** | 在该理想模型中证明“先等再维持”最优 |
| 能量守恒给出的下界 | **15.41 L** | 给定温度与热损假设下，任意可行策略的条件下界 |

水量 164.25 L，初始 40°C，温度限制 39–41°C，允许最大空间温差 1.5°C。表面散热由自然对流、辐射与蒸发的关联式推出（敞开水面约 35.6 W/(m² K)，按人体遮挡取 25），人体换热以[浸浴实验](https://doi.org/10.1113/EP092761)的核心温升为量级依据，混合系数没有依据，只作情景。没有实测浴缸实验；数值用于展示方法，不是普适的使用或安全标准。

**结果强烈依赖损失系数。** 在文献范围内取 64 个 Sobol 点，37 个点有可接受的恒定流量，所需水量 12–31 L（5%–95% 分位，中位数 21 L），其余点没有可接受方案。

## 看点在证据，而不只是曲线

- **空间差异会改变策略。** 三维有限体积热网络显式处理表面和壁面散热、人体置换及换热、内部混合、入流与溢流。每个单元都接受约束，平均值不能掩盖冷区。
- **结论等级分别表达。** 理想模型有最优性证明；空间模型有可行的恒定流量与分段方案；能量守恒有条件下界。恒定流量与下界之间 8.7 L 的差距，分段方案缩小到 4.4 L，其余差距保留。
- **验证不只重复运行。** 独立热流 RHS 的 RK45 对照矩阵指数，另核对能量、解析极限、几何算术和情景回放。17 项检查并不等于 17 套算法；分段方案另有 2 项检查。
- **检查采样点之间。** 基准策略使用导数包络核对全时间温度约束，并注明前提、浮点误差余量和适用模型。情景检查仍是采样验证，不借此扩大结论。
- **保留失败与修正。** 弱混合、紧温度窗等六个情景没有接受候选。最初的 40.5°C 上限在细网格上无解，随后上调到 41°C；最初偏低的损失系数也依据文献推导重设。细网格恒定流量水量 24.12 L（差 0.11%），两套网格仍只是诊断，不是收敛证明。

## 复现计算

在 Praxis 仓库根目录运行：

```bash
uv sync --locked
uv run --locked python demos/mcm-2016-a/reproduce/run_demo.py
```

脚本重算基准、17 个变化情景和细网格，执行 17 项模型检查，再增加 1 项与论文归档水量的比较。约需一分钟，实际时间随设备而变。输出写入 `reproduce/reproduced/`，存在时拒绝覆盖；它不会修改归档证据或最终 PDF。这里的 18 项复现检查不能回写成论文中 17 项模型检查。

分段流量优化与文献范围分析是可选的第二个入口，约需 4–5 分钟：

```bash
uv run --locked python demos/mcm-2016-a/reproduce/run_extended.py
```

它重算 3、6、12 段的最优方案、用独立 RK45 回放并检查 2 项，再对 64 个 Sobol 点做恒定流量搜索，结果写入同一个 `reproduced/` 目录。

[排版源与构建说明](reproduce/README.md)另列 PDF 工具、字体及命令。数学复现不依赖 AI 服务或排版库。
