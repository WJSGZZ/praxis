## 问题与难点

热水会散热，靠近水龙头和远处的温度也可能不同。题目要求用尽量少的热水，让浴缸保持接近初始水温，并分析浴缸形状、人体、动作和泡泡层的影响，最后给使用者一份说明。

**平均温度够高，不代表每个位置都温暖。** 此外，题目没有实测温度序列。研究先用可解释的理想模型建立基线，再检查空间差异、未知参数和供水误差是否改变建议。

## 主要结果

基准情景为 **30 分钟、164.25 L 水、初始 40°C**。所有单元温度不低于 39°C；入口射流区之外不高于 41°C，最大温差不超过 1.5°C，射流区半径取 0.15 m。

| 模型或方案 | 补水量 | 结论 |
|---|---:|---|
| 三维热网络：已接受的最佳恒流候选 | **24.14 L** | 空间差异下的比较基线 |
| 三维热网络：留余量的六段方案 | **21.48 L** | 比恒流少约 **11%**，三网格独立积分与条件连续时间检查通过 |
| 理想充分混合模型 | **16.01 L** | 在该模型中证明“先冷却到下限，再补水维持”最优 |
| 能量守恒下界 | **15.41 L** | 给定热损与温度假设下，任何可行策略都不能低于该界 |

空间方案是经检查的候选，未证明任意控制下全局最优。热损参数来自教材关联式及文献量级依据；混合系数作为情景输入。上述水量不属于实测节水率或现实使用标准。

### 关键发现

- **何时开始补水取决于输运。** 等待会缩短供水时间，也可能让远端过冷、迫使后续流量增大。已核验的局部分支中，基准混合适合立即供水，较强混合可从短等待获益。
- **更少的水不一定是有效答案。** 19.35 L 的十二段候选在最细网格出现 1.531°C 温差，超过 1.5°C，因而被拒绝。21.48 L 方案保留了设计余量。
- **测量要比较完整成本。** 同一合成读数、三种结构和共同设计余量下，被动观测／脉冲标定后的候选分别需 **26.09／23.63 L** 控制水量。脉冲另用 6 L；试验可复用、供水倍率稳定且总复位成本相同时，从第 **3 次**使用起更省。原结构的第 7 次交叉对应不同候选，不能混用。
- **等待也有明确边界。** 指定强混合 96 单元网络中，等待 780 秒后分两阶段供水的方案用 **19.26 L**，通过列明误差假设下的全程检查；等待至少 790 秒则排除所有不超过 3 L/min 的共同供水策略。两界之间仍有 10 秒未决。

## 建模方法

| 环节 | 方法及其作用 |
|---|---|
| 理想基线 | 整缸均温的热平衡模型，推导最优策略及能量下界。 |
| 空间机制 | 用守恒的三维有限体积热网络表示表面、壁面、人体、入流、溢流和内部混合，保护各位置的温度。 |
| 策略选择 | 比较恒流与分段流量；结合敏感度和正反等待证据解释行动，而非只报告优化结果。 |
| 测量与反馈 | 保留所有与读数相容的模型，检查下一步动作及剩余备份方案；观测不再支持模型时重新判断。 |
| 题目扩展 | 分别改变形状、人体、动作和泡泡层对应的机制，核查结论的条件依赖。 |

这里的“相容模型”指在声明的测量误差内仍能解释读数的模型，不是概率分布。策略无需识别唯一参数才能接受，但必须在列明的相容范围内检查。

## 验证与适用范围

| 核验层次 | 证据及其边界 |
|---|---|
| 方程与实现 | 独立热通量、能量守恒、矩阵指数与独立积分互证；空域解析扩散例的最细观测阶约 1.98。 |
| 推荐方案 | 六段候选逐次重启独立积分，检查切换点及采样点之间的温度；三套网格分别核验。终点达标不能替代全程达标。 |
| 参数与结构歧义 | 公平余量比较覆盖 **5,796** 个模型—网格对象，54 个极端对象另作独立积分及能量检查。有限集合不能解释为真实可靠性。 |
| 反馈与失配 | 两个未用于设计的参数点完成全程；其他机制改变使模型集合清空。四个限定失配案例有另行核验的接续方案，最大指令水量 **30.76 L**，不属于进一步节水。 |
| 可达性的限制 | 固定弱混合有限网络的精确证书排除所有 0–3 L/min 可测供水时序；改变物理区域的三网格研究另行记录，未证明连续模型或真实浴缸不可行。 |

留余量的名义方案在声明的随机水龙头误差试验中也不是每次都合格；没有实测浴缸标定。论文因此分别说明数值接受、模型适用和实际执行的条件。

## 作品评议

这份完整作品的作者外 AI 参考意见为 **较强 Outstanding 竞争力，F–O 相邻范围**。主要优势是把理想热平衡、空间输运、策略选择、独立核验和使用者动作连接起来；新增闭网混合诊断进一步说明，两个测点读数相同不足以证明全域均匀。

意见未经真人评委校准，不是正式获奖记录。物理参数和人体运动尚未实测标定，历史 2016 页数上限未认证。当前 28 页稿的科学审阅、格式审阅及继承范围见 [核验说明](verification.json)。
